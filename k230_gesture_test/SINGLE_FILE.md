# K230 单文件联机版 V4.9

## V4.9 第三页：虚拟琴键（当前版本）

运行 `main.py`，点击顶部「3 琴键」。两排共 8 键：上排 C4、D4、E4、F4；下排 G4、A4、B4、C5，对应 MIDI 60、62、64、65、67、69、71、72。当前为单指单音，力度固定 100。按住发声，松手/滑出按键区域释放，滑入另一键先释放旧音再触发新音。音色和音量沿用第 2 页设置。

**本版琴键发声需要配套 FPGA 源码重新构建、烧录。旧 FPGA 固件只支持 K230 调音量/音色，不会响应琴键。** 已更新当前工程 `E:/GowinProjects/project/project/instrument_fixed_top/instrument_fixed_top.gprj` 引用的接收模块和顶层；本次没有运行综合/布局布线，没有生成新 `.fs`。现存同名 `.fs` 仍是旧产物，不能以文件存在判断已支持琴键。

队友从 GitHub 下载时，打开仓库内的 [`instrument_fixed_top.gprj`](../local_gowin/merged_candidate/project/instrument_fixed_top/instrument_fixed_top.gprj)。上面的 E 盘路径仅指开发者本机。若整合到更新的 FPGA 工程，应合入 `k230_control_rx.v` 的音符/保活输出以及顶层新增的远端事件合并通路，保留队友工程的其余更新，不要直接用旧顶层覆盖新版。

K230 仍只需要本目录 `main.py`，UART3 TX→FPGA J13-35/C20 和共地保持不变。声音由 FPGA 经 PCM5102A 输出，K230 屏幕只负责交互。第 1/2 页保持手势/调参功能；第 2/3 页使用快速触摸循环，保留完整视频与透明背景。

按住时每 250ms 发送一次 B6 保活，不重新触发包络；正常退出先发松键。FPGA 1 秒收不到对应音符保活会自动释放，防止断线/程序停止后持续挂音。释放遵循音色包络，编钟的自然衰减不会立刻消失。硬复位无法保证 Python 退出代码执行，由 FPGA 超时保护兜底。

当前发声器按音高识别音符，不区分触屏、实体键盘和 BLE 来源；测试时请避免这些输入同时按同一个音，任一来源松开可能释放该音。没有 FPGA 状态回读，K230 页面上的音色/音量仍是本地设定值。

- 触屏页：点击钢琴、吉他、编钟按钮直接选择；拖动下方滑条，范围 0–100%，每档 5%，0 为静音。点击滑条任意位置也可设置音量。

仍只部署这一个 Python 文件，系统库和模型沿用板上已有文件。无需更改 FPGA 固件或布局布线。UART3 接线不变：K230 12 针排针第 5 脚 TX → FPGA J13-35/C20，第 4/7 脚 GND → FPGA GND。

## 运行与开机启动

1. 在 CanMV IDE 停止正在运行的程序。
2. 先备份板子 `/sdcard/main.py`，再将本目录 `main.py` 保存到板子相同位置。
3. 在 IDE 直接运行这个文件测试。退出 IDE 并复位/重新上电可验证自动启动。
4. 控制台应显示 `K230 FPGA SINGLE FILE V4.7 UART3`、`K230 UART3: 115200 8N1` 和 `FPGA UART parameter control enabled.`；屏幕标题为 `K230 循环控制 V4.7`。

仍使用板上亚博固件库（包括 `libs/AIBase.py`、`libs/AI2D.py`）和 `/sdcard/kmodel/hand_det.kmodel`、`handkp_det.kmodel`。不把这些系统库或模型合进 Python 文件，也不需要重刷 K230 系统固件。

## 操作与接线

- 开始位于音色页。**握拳**保持约 0.5 秒，循环切换音色页／音量页；长时间保持只切一次。
- 音色页用 **剪刀手**保持约 0.5 秒，循环切换钢琴 → 吉他 → 编钟 → 钢琴。协议仍为 0、1、2。
- 音量页用 **张掌**保持约 0.5 秒启用高度调节：抬高增大、降低减小，仍以 5% 为一档缓慢跟随。非张掌或离手立即停止调节，保持原值。
- 每次换页或换音色后，先张掌／放松约 0.3 秒，或把手移出画面约 0.6 秒，再做下一次操作。不接受操作手势之间直接跳转，避免识别误跳造成连续换页或换音色。
- 取消单指、点赞、三指操作。音量页做剪刀手只会提示先换页，不显示无效确认进度。确认进度最高显示 99%，真正执行时显示“已执行”；启动时不发送默认参数。
- K230 **12 针排针第 5 脚 IO32（UART3 TX）** → FPGA J13 第 35 脚（C20）；K230 **第 4 或第 7 脚 GND** → FPGA GND。K230 仍由外部 5 V 电源供电，串口为 3.3 V TTL / 115200 / 8N1。详见 [接线文档](FPGA_UART_WIRING.md)。

启动不强制覆盖 FPGA 参数；请实际改变一次音量或音色测试。屏幕“串口已发 N 条（无回读）”和每两秒控制台的 `STATE UART_TX` 表示本次运行已经提交给串口的命令数量。实际切换时还会显示“已发音色：…”或“已发音量…”。**计数增加仅说明软件调用发送，不表示 FPGA 已接收成功**；以 FPGA 屏幕和声音为准。FPGA 编码器的修改仍不会反向同步到 K230。

本次仅调整 K230 部署方式，FPGA 协议与引脚不变，无需为此重新布局布线。如果联机入口正确、TX 计数增加而 FPGA 完全没有反应，应继续检查接线及实际烧录的 FPGA 固件是否包含 K230 接收模块。

## V4.7 接口修正（2026-10-25）

用户实际使用的是 12 针 GPIO 排针，原 V4.6 程序使用 IO9/IO10 UART1，属于另一个接口。
现已统一为 IO32/IO33 UART3；正式控制只接第 5 脚 TX 和第 4/7 脚 GND，第 3 脚 RX 悬空。
回环测试先断开 FPGA 信号线，只短接第 5 脚和第 3 脚，运行 `uart_loopback_test.py`，应输出 `UART LOOPBACK V2` 和 `10/10 PASS`。
再断电移除短接，恢复 TX→FPGA J13-35/C20、两板共地，运行 `uart_link_diagnostic.py`（V2），最后运行 `main.py`（V4.7）。
不要将排针第 9/11 脚的 5V 或第 12 脚的 3.3V 接到 TX/RX。编号以用户提供的 12Pin GPIO 图和板上丝印为准。
本次已做电脑端引脚配置、协议和交互检查，实体回环及 FPGA 联动仍待验证。

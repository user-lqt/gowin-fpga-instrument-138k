# Member A Audio Delivery

## Production Configuration

`rtl/audio_core/` is the canonical source. Default `audio_core` has 32
independent voices; no audition defines are required.

| PARAM_INSTRUMENT | Sound |
| --- | --- |
| 0 | Upright-style acoustic piano (approved by member A) |
| 1 | Acoustic-style guitar |
| 2 | Bianzhong-style inharmonic bell |
| 3 | Compatibility alias of guitar, not a fourth sound |
| >3 | Falls back to piano |

Member B must display piano/guitar/bianzhong and cycle 0/1/2 from EC11_A.
Member C must include `guitar_body.v`, `plucked_string.v`, and
`bianzhong_candidate.v` along with the existing audio RTL in the Gowin
project. No system project, pin constraints, or common interface is changed
by this delivery. The old plan's electric-piano/organ/trumpet names are
superseded by this table; shared task documents still need team review.
Held voices retain their latched instrument when the global selection changes.

All samples are generated by HDL. Reference recordings are analyzed offline
for scalar parameters only, not embedded or played back as PCM.
`oscillator.v` implements the piano's four additive partials with continuous
stretched phase accumulators and register-dependent harmonic weights.
`adsr.v` provides fast piano decay followed by a quieter slow tail;
`voice.v` provides a brief hammer transient and velocity-dependent brightness.
The sample-derived model is an approximation, not a sample-library clone.

Guitar uses a fractional-delay feedback string and heuristic body filters.
MIDI 24..127 uses the string model; lower notes use an additive fallback.
Each timbre-enabled voice declares a 2048x16-bit string delay memory.
32 voices declare 1048576 delay-memory bits before optimization.
Bell uses eight separately decaying inharmonic modes. Its coefficients are
synthetic, not measurements of a historical bell.
The default outer NOTE_OFF release is 4800 samples for every sound.
The bell audition deliberately overrides release to 48000 samples; it is
not evidence that the default board release is one second.

## Regression Commands

Run from the repository root with Icarus Verilog and Python/numpy installed:

```powershell
.\sim\audio_core_tb\run.ps1 -Stage All
.\sim\audio_core_tb\run.ps1 -Stage A3Long
.\sim\audio_core_tb\run.ps1 -Stage Piano
.\sim\audio_core_tb\run.ps1 -Stage GuitarMelody
.\sim\audio_core_tb\run.ps1 -Stage BianzhongAudition
```

`All` runs A1, the five A2 tests, and the A3 short integration regression.
A1 is selected by `ENABLE_POLYPHONY=0`.
A2 uses `VOICE_COUNT=4`, `ENABLE_TIMBRES=0`, `ENABLE_STEAL=0`,
and `EVENT_DEPTH=16`; it rejects a fifth note rather than stealing.
A3 steals released voices first, then the quietest envelope, then the oldest
voice, then the lowest slot. Event overflow explicitly mutes until reset.
Parameter overflow is diagnostic without killing existing voices.
Quotient/remainder NOTE_OFF release lasts the configured sample count.

The short A3 test uses a 256-clock sample period and 64-sample release
override. It checks 32 independent phase increments, voice stealing,
instrument latching, velocity response, volume smoothing, saturation,
queues, reset and sample cadence. Different PCM does not alone prove
realistic instrument identity.
`A3Long` tests 32 bell voices over 4096 samples with mixer-reference checks,
50-clock valid latency and full 4800-sample release on every slot.
Per-slot note/frequency/phase/audio captures prevent counting harmonics as
independent voices. The audition captures A4 for each formal sound, with
24000 held, 4800 release and 2400 silent samples, and compares spectra.
Simulation cycle periods are accelerated; captured PCM is interpreted at
48000 Hz. These tests do not measure FPGA resource fit or end-to-end latency.

Generated data is ignored under `build/iverilog/waveforms/`:

- `a3_poly32.csv`, `a3_poly32_state.csv`: long 32-voice evidence.
- `a3_timbre_0.wav`, `a3_timbre_1.wav`, `a3_timbre_2.wav`: piano/guitar/bell.
- `a3_timbres_compare.wav`, `a3_waveform_spectrum.png`: spectrum comparison.
- `piano_upright_twinkle.wav`: approved upright-style piano, about 10 seconds.
- `piano_upright_note_60_soft.wav` and corresponding hard/69/78 variants:
  C4/A4/F#5 soft/hard strikes, decay and silent release checks.
- `guitar_twinkle.wav`: guitar melody.
- `bianzhong_single.wav`, `bianzhong_ode.wav`: bell single note and melody,
  with one-second audition release.

`analyze_piano_reference.py <samples-dir> --ffmpeg <ffmpeg-executable>`
exports only scalar measurements to ignored `piano_reference_analysis.json`.
It needs scipy-free numpy and an external FLAC-capable ffmpeg.
Original FLAC files and generated audio are not committed.

## Remaining A3 Evidence and Integration

The formal sound selection is now implemented in the default build.
The physical EC11_A/24-key board path is B/C's work, not proven by audio-only
tests. Member C must still approve RAM inference, combinational division,
DSP/ROM cost, the sample deadline, Gowin synthesis/timing and board sound.
String-model tuning over the complete MIDI range remains unqualified.
Questa independent verification remains paused by member A.
Glide, pitch bend, FSR-controlled pitch vibrato, EC11_B and 64-voice upgrade
belong to the next stage; they are not marked complete here.
Voice stealing/retriggering has no dedicated crossfade; audible clicks must
be evaluated on board, even when functional regressions pass.

## Independent Questa and History

`questa.do` recompiles canonical sources into ignored `build/questa/`.
Its existing A1/A2 targets remain available; no Questa results are claimed.
`audio_core_sim/audio_core_sim.gprj` is the existing local audio project;
member C owns changes to the real system project.
`local_archive/legacy_sim/` preserves old A1/A2 projects and waveforms,
not production dependencies. Do not treat stale compiled debug units as
current verification. `a2-audio-local` points to the older A1 base, and the
old A2 stash must not be applied over repaired sources.
Untracked rejected flute/erhu prototypes may remain locally; they are not
part of this production delivery or exposed by `run.ps1`.

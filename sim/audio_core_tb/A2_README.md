# A2 四声部修复版（2026-09-26）

当前实现基于 A 的 `359f090`，已接入 C 的主工作区。修复记录见
`docs/A2_REVIEW_359f090.md`，整机验收见 `docs/STAGE2_VERIFICATION.md`。
原 C 实现保存在本地 `feature/audio-a2`，不再作为当前接口说明。

## 行为

- 默认四个独立声部，每声部有振荡器、力度和 ADSR。
- 48 kHz，音频时钟约 12.288 MHz；valid 延迟为 3 个音频时钟。
- Attack 480 样本，Decay 2400 样本，Sustain 45875/65536（约 70%），Release 严格 4800 样本。
- 同音重触发复用声部，保持相位和当前包络。松键进入 Release，尾音结束后回收声部。
- 四声部占用时拒绝第五个新音，不抢占仍在发声或释放的声部。
- 力度 0 无效，超过 127 钳位。混音固定除以 4，再施加用户音量；最大音量不会覆盖保护余量。
- 事件 FIFO 16 项、参数 FIFO 4 项。事件溢出后静音，复位恢复；参数溢出保留已接收的更新。
- 已实现正弦音色和运行时总音量控制。EC11 控制总音量；当前顶层只启用一个真实音色。

## 复跑

```powershell
.\sim\audio_core_tb\run_a2.ps1
.\tools\verify_stage2.ps1
```

使用本机 ModelSim 10.1d；第一条运行 A 的模块、A2 集成、A1 回归和波形数值检查，第二条包含键盘、编码器和 DAC 接收仿真。
日志和波形位于忽略的 `sim/audio_core_tb/build/iverilog/`。

## 实物验收

下载新 `instrument_top.fs`。依次试听单键、双键及矩阵对角线四键，逐个松键确认其余声音保留；检查 EC11 音量、复位恢复和连续 30 分钟运行。
无二极管矩阵采用每行每列各一键的组合，避免鬼键影响结果。第五键被拒绝是当前设计行为。
仿真通过不能替代实物音质、延迟和稳定性验收。

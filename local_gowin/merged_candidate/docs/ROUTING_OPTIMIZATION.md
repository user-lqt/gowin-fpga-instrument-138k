# 布线资源诊断与等效优化

目标：保留32复音、钢琴/吉他/编钟、24键独立力度阈值、双EC11和RGB显示。
修改仅在 audio_velocity_32，未改动 liu 或 undone。

## 已确认原因

优化前整机综合：118377 / 138240 逻辑单元（85.6%），39910寄存器，81 BSRAM。
音频是主要资源来源。按综合网表层次统计的 LUT/ALU 近似数量：
吉他弦模型28659、钢琴振荡器23642、包络13029、吉他共鸣滤波11468。
实际整机RGB模块约343，不需要削减显示功能。
A原始音频单独综合108840逻辑单元（没有键盘、显示与系统平台）；
相同默认参数、相同综合配置的优化前力度音频单独综合111508，
增加2668（相对原音频约2.45%，相对芯片总量约1.93个百分点）。
整机顶层还启用了表情参数等功能，不能与单独音频顶层直接比较。

## 保留的改动

- parameter_manager：默认0..127音量映射用移位和区间补偿，精确保留
  round(ui*65535/127)。通用配置的中间值由64位缩至足够的32位。
  默认参数单模块综合98逻辑单元；整机以最终报告为准。
- plucked_string：三处常数除法改成有界精确倒数乘法与移位，保留所有
  音频取样时序。单模块798降至745逻辑单元，但MULTALU27X18从2增至5，
  这是使用乘法器换逻辑的取舍；须检查整机布局布线资源可行性。
- 已试验显式选择吉他滤波状态，但占用增大，已恢复原实现。

## 验证

tools/verify_velocity.ps1 可重跑五组XSim测试，2026-10-07全部PASS：

- 三种音色力度响应：1197帧，音高不变。
- 三种音色32复音：3846帧，输出延迟109拍，节拍256拍，释放正常。
- 24键阈值、抖动、事件突发及释放。
- 吉他除法全部有效输入精确一致；三档力度12288帧PCM与修改前逐帧一致。
- 全部128档音量、默认首次事件、复位。

整机重新综合完成：112489 / 138240（81.4%），比原118377减少5888
逻辑单元（相对减少4.97%，占用下降4.26个百分点）；寄存器39902，
BSRAM仍81。MULTALU27X18从85增至179，MULT12X12仍2、MULT27X36仍5。
已开始布局布线；布线耗时和时序结果待最终报告更新。
单模块占用下降不能证明整机布线一定更快，仿真不能代替板上试听。

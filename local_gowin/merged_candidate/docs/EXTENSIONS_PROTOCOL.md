# 脱机、节奏与蓝牙扩展使用说明（2026-10-15）

## 工程和接线

打开 `project/instrument_velocity_32_two_timbres/instrument_velocity_32_two_timbres.gprj`。
先重新综合，再布局布线，烧录新生成的fs。旧fs不包含这些功能。
ESP沿用已经打通的FIX3 main.c，不需要修改；本次未改ESP源码。

- ESP GPIO21 TX → FPGA C18 RX。
- FPGA C19 TX → ESP GPIO20 RX（此次真正启用回传，必须接此线）。
- GND共地，UART 115200/8N1，3.3V逻辑。
- 手机服务001，写002，订阅003。调试器接收选HEX，发送选HEX。

录制是演奏事件（音符、力度、时间），不是PCM或麦克风声音文件。
所有曲谱、映射、录制均在RAM中，复位/掉电后清除；两首内置练习曲不受影响。

## 1. 脱机选曲

EC11_B短按页面顺序：GLIDE → FX → SONG → TEMPO → TEST → ANALYSIS → GLIDE。
SONG页旋转选1/2/3，长按启动/重新开始。1茉莉花，2指纹高潮60音，3手机上传曲谱。
第三曲未上传时显示未录入。自由练习下，按对实体键才推进，重复音需松开重按。
完成后24个琴键对应灯全亮，退出页面灯灭；重新进入先等待本地长按或手机指令。
蓝牙仍可选择曲目；本地功能不依赖手机或ESP是否连接。
K6不作为内置或下载曲谱的演奏目标；完成时K6对应灯允许亮。

## 2. 节奏练习

默认自由练习。手机发B1选择自由/节奏，再用B2设置40～200 BPM；运行中切换自由/节奏会从头重练，进入节奏时重新四拍预备。
TEMPO页也可旋转调整速度；调整后返回SONG重新启动。
启动有四拍预备；随后按曲谱时值自动推进，漏按不会卡住。
目标灯在拍点提高亮度，屏幕左侧节拍指示同步闪烁；休止符不亮目标灯。
预备期间按键提示EARLY；目标起点后150ms内首次按对提示GOOD，超过150ms提示LATE。
到下一个音符仍未按对提示MISS。此版本评分关注起音，不评价松键时长；相邻重复音仍须重新按下。
内置曲谱采用简化练习时值，尤其指纹仅为入门单音副歌，不宣称原版演唱逐音节拍完全一致。
上传曲谱支持明确时值与休止，单位为八分音符：四分音符=2、二分音符=4、全音符=8。

## 3. 手机页面与在线下载

页面：`tools/phone/index.html`，同时部署同目录`protocol.js`和`app.js`到HTTPS静态站点。更新后页面顶部版本应为20261015b。
Android Chrome打开HTTPS地址后，点连接蓝牙，选择FPGA设备。页面自动订阅003并查询FPGA状态。
可导入txt/csv曲谱，或读取HTTPS在线曲谱URL（服务器须允许跨域CORS），检查后点击发送。
未替用户发布到互联网；本地HTTP局域网地址通常不满足Web Bluetooth安全上下文要求。
iPhone Safari不支持此网页蓝牙；可以继续用现有BLE调试器手动按下面协议操作。

曲谱格式每行两列：物理键号 时值，例如：

```text
1 2
1 2
8 2
8 2
10 2
10 2
8 4
0 2  # 休止
```

最多128项。键号0=休止，1～24=实体键，禁止6；时值1～32。
上传流程C0开始 → 依次C1传每项 → C2确认完整后发布到第三曲槽。
上传中不得启动第三曲，已开始演奏时不能开始上传。错误/中断可C3终止并重新开始。
这里支持的是手机→设备传入新曲谱，不再仅是选择内置曲目。
不含互联网曲库服务、自动识别图片或自动解析任意MIDI曲谱。

## 4. 自定义键位

手机输入键号和MIDI音符，松开所有键后点击修改。默认K1=60，K24=83。
避免重复音符映射；要交换两键，可先暂移其中一键至空闲音符再交换。
例如K1→84。按键的NOTE_OFF使用按下时锁存的音符，防止改映射造成挂音。
LED曲谱按实体键编号，映射改变会改变曲谱实际音高，规范演奏前应恢复默认映射。

## 5. 录制、回传与回放

页面点开始录制 → 演奏 → 停止 → 取回记录 → 保存JSON/MIDI。
记录实体键映射后的事件和手机音符事件，排除复音验收模式。
最多512事件（一次按下+松开占2条），时间分辨率1ms；尝试写入第513条时停止，状态标明溢出，保留前512条。回传每包间隔30ms，满容量约需16秒，请等数量完整后再导出或回放。
取回时检查记录序号和总数；通知丢失则不能导出，请重新取回。
导出的MIDI可在支持MIDI的软件中播放，音色不保证与FPGA一致。
页面也可导入已保存JSON，按事件时间回放到FPGA；手机BLE调度会带来额外抖动，不是专业实时MIDI接口。
回放结束/手动停止会发送剩余NOTE_OFF，避免挂音。

## 6. 调试器完整发送帧

所有命令5字节：`A5 CMD A B XOR`，XOR=前四字节异或。
每发送一条控制命令，等待FPGA的F0回执后再发下一条，避免回执队列溢出。

| 功能 | CMD | A | B | 示例完整帧 |
| --- | --- | --- | --- | --- |
| 选内置1/2或下载3 | B0 | 1～3 | 0 | `A5 B0 02 00 17` |
| 自由/节奏 | B1 | 0/1 | 0 | `A5 B1 01 00 15` |
| BPM | B2 | 40～200 | 0 | 80 BPM：`A5 B2 50 00 47` |
| 开始上传 | C0 | 项数1～128 | 0 | 7项：`A5 C0 07 00 62` |
| 追加一项 | C1 | 键号0～24（禁止6） | 时值1～32 | K1四分音符：`A5 C1 01 02 67` |
| 发布曲谱 | C2 | 0 | 0 | `A5 C2 00 00 67` |
| 终止上传 | C3 | 0 | 0 | `A5 C3 00 00 66` |
| 设置键位 | D0 | 键号1～24 | MIDI音符0～127 | K1→84：`A5 D0 01 54 20` |
| 恢复键位 | D1 | 0 | 0 | `A5 D1 00 00 74` |
| 开始新录制 | E0 | 0 | 0 | `A5 E0 00 00 45` |
| 停止录制 | E1 | 0 | 0 | `A5 E1 00 00 44` |
| 取回录制 | E2 | 0 | 0 | `A5 E2 00 00 47` |
| 状态查询 | F0 | 0 | 0 | `A5 F0 00 00 55` |

原90 NOTE_ON、80 NOTE_OFF仍兼容；90力度0视为NOTE_OFF。
节奏和速度命令可在演奏中设置；切换自由/节奏模式会重启当前练习。网页每次开始都会先发送所选模式和BPM，再选曲，避免沿用旧模式。
手机选曲须先进入SONG。下载成功不自动开始第三曲，需选3启动。

## 7. FPGA回执与记录包

FPGA回包固定12字节：`A6 KIND PAYLOAD[9] XOR`，最后一字节使整包异或为0。
多字节整数低字节在前。BLE通知可能分片或合并，不可假设一次通知就是一个包。
ESP原有ASCII `UART OK 5`可与二进制通知混合；网页解析器会跳过ASCII，识别A6包及校验。

- KIND=F0：字节2=CMD，3=结果，4..5=数据，其余负载0。
- 结果0成功、1未知指令、2无效参数/音符重复、3忙/页面不符、4曲谱未完成/未录入。
- KIND=E0：字节2=事件类型1按下/2松开，3=音符，4=力度，5..8=毫秒，9..10=序号。
- KIND=E1：字节2..3=事件总数，4=录制溢出，其余0；表示本次取回结束。
- 查询F0数据：位9..0=事件数，10=录制，11=回传，12=录制溢出，13=回执溢出。

这些回执证明FPGA处理了指令；ESP的UART OK只证明串口发送完成。
传输发生在单一时钟域，音符合并FIFO保留同拍实体/蓝牙事件并检测溢出。

## 8. 屏幕

主页面波形和XY使用仅显示自动增益，声音不受影响。
新增ANALYSIS页：XY放大到256×256；频谱16柱，旋转EC11_B选择柱，显示中心Hz及相对等级。
中心Hz是分析频点，不是高精度测频值；等级未标定dB。它是16频点DFT，不是完整FFT。
为减少布线压力，节奏调度用相位累加器和时值计数，不采用运行时除法器。

## 验证与现场验收

仿真检查：脱机启动、四拍预备、休止/正确/漏按、曲谱事务和K6拒绝、映射及同拍事件、录制时间戳、UART实际串行回包。
手机协议检查：分片/混合通知、校验拒绝、曲谱参数、时间戳、MIDI编码。
这些通过不等于板上验证。仍需用户运行综合/时序/布局布线并按上述顺序上板测试，手机实连、在线URL访问及实际音效尚未现场验证。

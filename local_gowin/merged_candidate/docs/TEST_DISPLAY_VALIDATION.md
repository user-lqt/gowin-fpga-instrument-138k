# TEST 专页与实时反馈验收

## 操作

短按 EC11_B，按 GLIDE → FX → SONG → TEMPO → TEST → ANALYSIS 顺序切页。
在 TEST 页长按 EC11_B（约 0.8 秒），启动/停止原有测试音源。
启动时先清理音符，再依次加载 MIDI 48～79 共 32 个音；待加载完成查看 ACTIVE 32/32。
32 格蓝条表示音频核心报告的活动声部数量，不是 32 路独立声部电平。
切页不自动停止测试，需回到 TEST 页长按停止。停止后先松开所有实体琴键，再恢复普通演奏。
主页面已删除原有 TEST ON/OFF 文字。

## 显示含义

- 波形：实际效果器输出的单声道采样，48 kHz、每两个样本取最小值/最大值，512 列共 1024 个样本、约 21.33 ms 视窗。自动幅度缩放，不能比较不同时间的绝对电平。
- 频谱：既有 512 点矩形窗、16 个选定频点的 DFT，相邻完整 DFT 栅格间隔 93.75 Hz，显示近似对数幅度。不是完整 FFT、不是校准 dB，也不是逐声部频谱。混合音与泛音会重叠，不能由可见峰数推断复音数。
- 频谱计算窗口约 10.67 ms；屏幕只在帧边界更新，受现有像素时钟、帧率及跨时钟传输影响，不承诺每窗可见。
- XY：同一单声道当前样本与延迟 24 点（0.5 ms）的样本，非左右声道相位分析。1024 点轨迹、双缓冲、帧边界交换；波形改变时轨迹也随之改变。
- TEST 页的频谱沿用真实混音输出，不根据 ACTIVE 数字绘制假频谱。
- ANALYSIS 页保留放大频谱与 XY，旋转 EC11_B 选择频点，显示频率（Hz）和相对幅度。

## 上板实测（需要用户执行，尚未实测）

1. 重新综合、布局布线、烧录当前 instrument_fixed_top.gprj。不要使用旧 .fs。
2. 普通页演奏单音、快慢力度，记录波形有无更新、频谱是否变化、XY 是否变化；自动缩放会弱化屏幕上力度的幅度差异。
3. TEST 页长按，等待 ACTIVE 32/32 和 32 格全部变蓝。确认波形非直线、频谱非全零、XY 有轨迹。拍照或录像，记录时钟、音色、音量。
4. 长按停止，松开所有键，等待至少 1 秒，确认声部数归零、频谱回落、波形趋于中心线。音色释放尾音、效果器尾音未结束时不要求立刻归零。
5. 在音频测试源可提供已知单音时，使用 750 Hz 检查 ANALYSIS 的第 6 频点（750 Hz）为主峰；再测 1500 Hz，受所选频点与矩形窗泄漏影响，不要求峰值落在精确 1500 Hz。
6. 750 Hz 单音的延迟 XY 应为椭圆类轨迹；这仅检查延迟轨迹正确，不用于判断立体声相位。
7. 连续运行 5 分钟，切换普通/TEST/ANALYSIS，记录有无花屏、卡住、旧轨迹滞留、明显音频卡顿。若异常，保留屏幕录像与生成报告再定位。

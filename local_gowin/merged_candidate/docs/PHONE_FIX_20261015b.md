# 手机网页与回传修正 20261015b

## 更新方法

1. 关闭Gowin旧工程，不保存旧文件列表；重新打开原gprj，确认instrument_link.v和performance_event_merge.v来自rtl/input。src中的旧副本保留但不参与编译。
2. 用户重新综合、布局布线、烧录。本次未运行这些步骤。
3. 将tools/phone下index.html、protocol.js、app.js、example_score.txt一起更新到现有HTTPS网站的同一目录。app.js是新增文件，不能只更新index.html。
4. 手机刷新网页，必要时清理站点缓存，确认顶部版本20261015b。
5. 点连接蓝牙；断开后可用同一按钮重连，重连重新获取服务和特征。

## 修正内容

- 恢复默认成功后更新当前键输入框；选键时显示本网页已确认的映射。设备在网页之外单独复位时，需再次恢复默认同步，未新增全表查询。
- 开始曲目时明确发送自由/节奏及BPM。模式命令允许运行中修改，切换模式会从头重练。
- 录制回传每个事件包增加30ms间隔，降低ESP蓝牙通知负载；512事件约16秒。
- 网页等待结束包、记录序号与总数一致才允许保存；取回过程中阻止其他按钮操作。
- 断连立即取消待回复/待取回操作，重连重新订阅通知；已完整取回的数据可在断连后保存JSON/MIDI。
- 未修改ESP固件。断连具体原因仍需现场确认；节流和连接管理修正不保证解决所有ESP复位、供电或无线问题。

## 验证

六项FPGA仿真通过，新增运行中自由/节奏切换、不按键不推进的断言。
手机协议测试与app_test.cjs通过；后者模拟GATT，覆盖恢复默认、模式指令顺序、取回中断连、重连及离线导出。
顶层Icarus编译展开通过（忽略厂商PLL黑盒）；不代表Gowin综合或手机实连已验证。

先录制2～4次按键，松开所有键→停止→取回→等“数量完整”→导出。如果仍断开，请保存ESP monitor中断连前后的日志，区分蓝牙断连与ESP重启。

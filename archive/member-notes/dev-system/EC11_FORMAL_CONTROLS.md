# EC11 正式交互版

构建入口：`tools/build_ec11_formal.tcl`，顶层 `instrument_24_rgb_top`。
烧录文件：`project/instrument_24_rgb_ec11_formal/impl/pnr/instrument_24_rgb_ec11_formal.fs`。
旧 J13 诊断版烧录文件保留，正式版需要重新上板验收。

接线不变：EC11 A→J13-17/A21，B→J13-18/B21，D→J13-19/B18；
C/E→GND。A/B/D 分别用 4.7kΩ 上拉到 3.3V，不接 J13 的 5V。

- 旋转始终调音量，每格 4，范围 0–127，默认 64。
- 短按循环切换 0→1→2→0，不再切换页面。长按只产生一次切换。
- 音色 0=正弦波、1=三角波、2=锯齿波。
- 音色由音符起音时锁存；切换后重新按琴键才能听到新音色。
- 按键消抖按约 12.288MHz 音频时钟设置为 20ms；旋转滤波保持已上板
  有效的 2500 时钟设置。音量出口继续映射为 0–65535 线性增益。
- 屏幕保留音量条、音色位置标记与琴键显示，去掉诊断方块和计数条。

验收：复位后音量条约一半；旋转能改变长度，转到最低应静音；连续短按
三次，顶部音色标记回到最初位置。每次切换后重新按同一琴键比较音色。

自动测试 `tb_ec11_formal` 覆盖步进、音量上下限、三音色循环、按键抖动/
长按、同拍旋转和按压、音频参数接收、屏幕诊断区域清除及复位。
`tools/verify_strike_expression.ps1` 同时复跑原诊断、琴键、击键表情和整机测试。
当前音频仍为四复音，32 复音不属于本次改动。

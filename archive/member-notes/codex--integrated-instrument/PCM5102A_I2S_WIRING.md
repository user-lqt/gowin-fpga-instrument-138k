## 实际接线表

FPGA引脚来自31005 Rev1.3底板J13/SDRAM0连接器及BANK2原理图。优先认排针旁丝印A19/E16/E17，不靠目测数排针位置。

| PCM5102A模块丝印 | 接哪里 | 说明 |
| --- | --- | --- |
| BCK | FPGA J13 **A19**，物理J13-23 | 位时钟，顶层仍名o_hp_bck |
| LCK / LRCK | FPGA J13 **E16**，物理J13-28 | 左右声道时钟，顶层仍名o_hp_ws |
| DIN | FPGA J13 **E17**，物理J13-31 | 串行音频数据，顶层仍名o_hp_din |
| GND | FPGA GND，可用J13-12 | 所有地共地 |
| 3.3V | FPGA底板明确标注的+3V3电源 | 可从PMOD J8/J9的+3V3取电，原理图为1/2脚；须核对方向和丝印 |
| XMT / XSMT | 与上行相同的3.3V电源 | 高电平解除静音，不能悬空 |
| FMT | GND | 选择Philips I2S；接高会变为左对齐 |
| SCK | GND | 无外部MCLK，使用PCM5102A内部PLL；若实物已焊接至地，不必重复接线 |
| VCC / VIN | 不接 | 依本包文字修正，避免与3.3V脚同时供电 |
| FLT（如引出） | GND | 默认正常延迟滤波；已固定的焊桥无需改动 |
| DMP（如引出） | GND | 关闭去加重，适用于当前48kHz音频 |

J13的5V电源不能当3V3用；A19/E16/E17是信号脚，不能拿来给模块供电。
本模块使用的3.3V/GND/FMT/XMT/SCK是直接连电源或地，不需要上拉/下拉电阻。
三根音频线尽量短，建议10～15cm内，时钟线附近带地线，不穿过LED大电流供电回路。
如果J13插有SDRAM扩展板，先拔掉再使用这些引脚。

## 声音从哪里出来

将有源音箱或功放输入接到 **PCM5102A模块的LINE OUT/AUX**，不是Tang Mega板载耳机口。
若用L/G/R焊盘：L接左输入、R接右输入、G接音频地。左右输出不要短接在一起。
PCM5102A是线路输出，裸喇叭需要功放；低阻耳机建议经耳放使用。
FPGA原板载PT8211音频引脚Y17/AB17/AA16已从当前顶层约束释放，原板载音频口不作为本版输出。

## 接口格式与时钟

- Philips标准I2S，WS低=左，WS高=右；WS跳变后延迟一个BCK再发送新声道MSB。
- 每声道32位槽，24位有符号PCM，高位先发、低位补0。左右同播当前音效处理后的单声道声音。
- 保留24位PCM，不再截成16位。
- 名义采样率48kHz、BCK=3.072MHz、每帧64 BCK，无需外部MCLK。
- 现有音频PLL实际为50MHz×29/118，约12.288136MHz；对应Fs约48000.53Hz、BCK约3.072034MHz，仍沿用原采样时基。
- `sample_scheduler`位时钟分频由4改为2；SDC的dac_bck分频由8改为4。
- WS/DIN在BCK下降后更新，为DAC上升沿采样留出建立时间；左右样本在同一帧起点一起锁存，避免串帧。

## 验证与上板

已运行 `tools/verify_pcm5102a.ps1`，独立接收器在实际输出引脚上检查：标准I2S的一位延迟、左右声道极性、24位正负数据、32位槽、64BCK/帧、填零、两声道同帧锁存、静音及复位。
日志和波形：`sim/audio_core_tb/build/pcm5102a/pcm5102a.log`、`pcm5102a_i2s.vcd`。
顶层还需用户运行Gowin综合、时序分析和布局布线，仿真通过不代替实板验证。

1. 断电按表连接；确认FMT=0、XMT=3.3V、SCK=0，模块3.3V电源正确。
2. 重新打开工程，用户自行综合、布局布线并烧录新fs。
3. 音箱先调低音量，插在外接模块LINE OUT；按K1/K3/K5试听，所有原演奏和指引功能继续使用。
4. 无声时先查模块供电和静音脚；有逻辑分析仪则测A19约3.072MHz、E16约48kHz，E17按键时有音频数据。
5. 有杂音时优先确认FMT接地、线序、共地和杜邦线长度，检查是否仍烧录旧fs。

本次没有运行综合、布局布线或烧录，也没有修改ESP固件或手机网页。

# 成员 C 零基础学习路线

> 面向"完全没学过 FPGA"的人，目标是**先让耳机响，再谈别的**。
> 你不是要"学会 FPGA"，你是要**在 4 周内能独立写出 I2S 输出链路**。学习内容按这个唯一目标裁剪。

## 0. 先建立最重要的一个观念（比语法重要十倍）

### Verilog 不是编程，是**画电路**

| 你的直觉（软件思维） | FPGA 的真实情况 |
|---|---|
| 代码一行行往下执行 | 所有 `always` 块**同时在跑**，永不停止 |
| `a = a + 1` 是"把变量加一" | 这是"每来一个时钟沿，把寄存器更新成它的下一个值" |
| 需要循环就写 `for` | 循环是用来**复制硬件**的，不是用来"跑很多次" |
| 有函数调用、有栈 | 没有栈、没有调用，只有**连线**和**寄存器** |

**最容易踩的坑**：在 `always @(posedge clk)` 里写"顺序逻辑"并且在同一个块里既读又写同一个信号。那不是软件里的变量自增，而是在描述一个寄存器。

### 记住两个模板就够用了

**① 时序逻辑（有记忆的电路）—— 你 90% 的代码都是这个形状**

```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        cnt <= 0;              // 复位时给一个确定的初值
    end else begin
        cnt <= cnt + 1'b1;     // 每个时钟上升沿，cnt 变成"当前值+1"
    end
end
```

- 用**非阻塞赋值** `<=`
- 复位分支永远写在最前面
- 括号、`begin/end` 一定配对

**② 组合逻辑（没记忆的电路）—— 只在需要"算一下"时用**

```verilog
assign y = a & b;                          // 最简写法
// 或者
always @(*) begin
    case (sel)
        2'd0: y = a;
        2'd1: y = b;
        default: y = 1'b0;                 // ★ 一定要有 default，否则会推出锁存器
    endcase
end
```

- 用**阻塞赋值** `=`
- `case` 必须写 `default`
- **不要在组合逻辑里写时钟**

## 1. 什么是时序（不懂这个，板子永远不工作）

**FPGA 里所有动作都由时钟的上升沿驱动。** 100 MHz 时钟 = 每 10 ns 一次上升沿。

| 概念 | 白话解释 | 对你的影响 |
|---|---|---|
| **时钟周期** | 两个上升沿之间的时间。100 MHz → 10 ns | 你写"一个操作"，实际是 10 ns 完成一个节拍 |
| **时钟频率** | 每秒多少拍。12.288 MHz = 每秒 1228.8 万拍 | 你的 I2S 位时钟就是它分频来的 |
| **复位** | 上电后把电路拉到已知状态 | 不复位 = 寄存器是随机值 = 上电可能爆音 |
| **同步** | 所有寄存器用同一个时钟 | 跨时钟域的信号必须同步，否则**偶发**出错（最难查的 bug） |
| **亚稳态** | 信号在时钟沿附近变化，采样结果不确定 | 用**双触发器**同步外部输入 |
| **抖动** | 时钟周期忽长忽短 | 赛题要"确定性无抖动延迟"，所以音频域用 12.288 MHz / 256 整除 |

**把时钟想成心跳**：每个寄存器在心跳时刻"看一眼输入，把输出更新成那个值"。心跳之间的任何变化，都要等到下一次心跳才生效。

## 2. 四周学习路线（每周有可验收的产出）

### 第 1 周：语法 + 数字电路基础

**学什么**

| 内容 | 你只要学到 |
|---|---|
| `module` / `endmodule`、端口 `input` `output` | 会定义一个模块 |
| `wire` vs `reg` | `wire` = 连线；`reg` = 寄存器（在 `always` 里赋值） |
| `always @(posedge clk)` | 会写计数器 |
| 位宽 `[7:0]`、signed | 知道 8 位能存 0~255 |
| `if/else`、`case`、`begin/end` | 会写状态机 |
| 三种赋值：`assign` / `=` / `<=` | 知道什么时候用哪个（见上方模板） |
| 二进制与十六进制 | 会算 `8'hFF` = 255 |

**不要学**：类、复杂编译指令、SystemVerilog 高级特性、UVM 验证。

**动手项目（全部要真跑仿真）**

1. **LED 闪烁**：用计数器把 100 MHz 分频到 1 Hz 驱动 LED
2. **按键消抖**：外部按键抖动 → 连续三次采样一致才算有效
3. **8 位计数器 + 数码管/LED 显示**
4. **移位寄存器**：8 位数据的串行输出（这是 I2S 的核心！）

**验收标准**：`tb_led.v` 里给时钟和复位，跑仿真，看到 LED 信号按预期周期翻转。

**推荐资源**

- HDLBits（在线做题，浏览器里写代码立刻判分）：<https://hdlbits.01xz.net/wiki/Main_Page>
- Verilog 教程：<https://www.runoob.com/w3cnote/verilog-tutorial.html>
- asic-world（英文，例子多）：<https://www.asic-world.com/verilog/index.html>
- 小梅哥 FPGA 教程（中文图文，适合入门）

### 第 2 周：Gowin 工具链 + **先把声音弄响**

**这是整个学习路线上最重要的一周。** 在你自己写任何代码之前，先把官方的例子烧进去听到声音。

**学什么**

| 内容 | 你只要学到 |
|---|---|
| 云源软件建工程 | 选器件、加文件、设顶层 |
| 器件选择 | **`GW5AST-LV138PG484A` + 封装 `PBG484A` + 版本 B 或 C** |
| 综合（Synthesize） | 把 Verilog → 电路。看报错信息 |
| 布局布线（Place & Route） | 把电路摆到芯片里。卡在 50%/70% 是**正常的**，等一会 |
| 管脚约束 `.cst` | 告诉工具"这个信号从哪个物理管脚出去" |
| 时序约束 `.sdc` | 告诉工具时钟频率 |
| 下载器 | 板载 USB，按 PWR 键 2 秒开机 |

**动手项目**

1. **点灯**：自己建工程，写 LED 闪烁，烧进去看到灯闪 → 证明整条链路通
2. **★ 跑通官方 I2S 例程**：克隆 <https://github.com/sipeed/TangMega-138K-example>，进 `audio_i2s/`，编译烧录，**插耳机听到 400 Hz 梯形波**

**验收标准**：耳机里真的响了。

> 这一步的意义：它一次性验证了 **IDE + 许可 + 板子 + 下载器 + DAC + 功放 + 耳机** 全部正常。
> 之后出问题，你可以确定**问题在自己的代码**，而不是环境。这是新手最需要的那块"确定性"。

**⚠️ 注意**：例程里 138K 的器件版本，官方写的是 **B**。你要看**芯片顶面丝印**确认，选错会"烧录成功但管脚毫无反应"。

### 第 3 周：I2S 协议 + 时钟域

**学什么**

**① I2S 是什么**

三根线，把数字音频送到 DAC：

| 线 | 含义 | 我们的参数 |
|---|---|---|
| `HP_BCK` | 位时钟，每一位数据配一个脉冲 | 3.072 MHz |
| `HP_WS` | 声道选择，**低电平 = 左声道** | 48 kHz |
| `HP_DIN` | 数据，MSB 先出 | — |

关系：`BCK = 每声道位数 × 2 × LRCK`。我们每声道 32 位 → 3.072 MHz = 32 × 2 × 48 kHz。

**② 时钟域划分**

```
外部晶振 ──PLL──┬──> clk_fsys  100 MHz   系统、键盘扫描、UART
                └──> clk_fs    12.288 MHz  音频域
                        │
                        ├─/256──> sample_tick  48 kHz（音频节的唯一节拍）
                        └─/4────> HP_BCK       3.072 MHz
```

**为什么用 12.288 MHz**：12.288 MHz ÷ 256 = 48000，**整除、无累积误差、无抖动**。如果用 100 MHz 去分频，100000000 ÷ 48000 = 2083.33，除不尽，会产生抖动。

**③ 异步输入同步**

键盘、编码器这些外部信号相对时钟是异步的，必须**双触发器同步**：

```verilog
reg a_d1, a_d2;
always @(posedge clk) begin
    a_d1 <= key_in;    // 第一级：可能有亚稳态
    a_d2 <= a_d1;      // 第二级：稳定了
end
// 之后只用 a_d2
```

**动手项目**

1. **写 `sample_scheduler`**：从 12.288 MHz 产生 48 kHz 的 `sample_tick` 单拍脉冲
2. **写 `i2s_tx`**：把 24 位数据串行输出到 `HP_DIN`，同时产生 `HP_BCK` 和 `HP_WS`
3. **仿真验证**：`HP_WS` 周期是不是 1/48000 秒，`HP_BCK` 是不是 64 倍

**验收标准**：仿真波形里 LRCK = 48 kHz、BCK = 64 × LRCK、数据与声道对齐正确。

### 第 4 周：接上音频核心 + 学会看证据

**学什么**

1. **握手机制**：`valid` 信号怎么工作（数据有效脉冲）
2. **从仿真到上板的差距**：仿真对了不代表板子对，**必须实测**
3. **逻辑分析仪**：抓 I2S 三线，量周期、数位数
4. **复位策略**：异步置位、同步释放（仓库里 `rtl/common/reset_sync.v` 已经写好了，你读懂它）
5. **固定点思维**：FPGA 里一般不写浮点，24 位音频就是整数

**动手项目**

1. 把固定正弦波表接到 `i2s_tx`，耳机里听到**纯正弦音**
2. 用逻辑分析仪抓三线，确认参数
3. 在仓库的 `rtl/system/` 里按任务书把模块一个个写出来

**验收标准（C1 的硬门槛，就是你任务书里的原文）**

- [ ] LRCK 实测 **48 kHz**
- [ ] BCK / DATA 对齐正确，**无一位错位**
- [ ] 左右声道稳定，耳机口持续发声
- [ ] 无严重杂音、爆音、周期性中断
- [ ] **有逻辑分析仪波形证据**

## 6. 遇到问题怎么问（这个技巧能省你几十小时）

**不要**说："我的代码不工作，怎么办？"

**要**给出这四样：

1. **我想做什么**：把 48 kHz 的采样通过 I2S 送到 DAC
2. **现象是什么**：耳机里有杂音 / 逻辑分析仪上 LRCK 是 96 kHz 不是 48 kHz
3. **我看到了什么**：仿真波形截图 / 逻辑分析仪截图 / 综合报错原文（**全文，别截断**）
4. **我已经试过什么**：改过分频比、换过管脚

**报错信息要贴原文。** 工具报的错通常很具体，比如：
- `WARN (EX3791) : ... no constraint` → 管脚没约束
- `ERROR (CT1013) : Failed to find the module` → 顶层模块名写错
- `ERROR (PR2017) : ... cannot be placed` → 管脚冲突或器件选错

## 7. 一句话总结

> **第 1 周学会写计数器；第 2 周让官方例程在耳机里响；第 3 周自己写出 I2S；第 4 周用逻辑分析仪证明它是对的。**

## 8. 现在就能开始的第一个练习

不用等板子，现在就能做（需要装 IDE 或用在线工具）：

**目标**：写一个模块，输入 100 MHz 时钟和低有效复位，输出一个 1 Hz 的方波。

**关键提示**
- 100 MHz 一个周期是 10 ns，1 Hz 半周期是 0.5 秒 = 500,000,000 ns = **50,000,000 个时钟**
- 需要一个 26 位以上的计数器（2^26 = 67,108,864 > 50,000,000）
- 计到 49,999,999 时清零并翻转输出

先自己写，写不出来再看答案 —— 仓库里的 `rtl/common/reset_sync.v` 是一个可以直接参考的、写得规范的例子（它是我们项目真实在用的代码）。

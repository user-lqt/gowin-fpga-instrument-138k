> 归属：成员 C。本文定义**第二批次要交付什么、怎么验证**。
> 上一批次见 [`evidence/stage1/C1_批次1_时钟与采样节拍.md`](../../evidence/stage1/C1_批次1_时钟与采样节拍.md)。

## 1. 为什么需要这个批次

批次 1 交付了时钟与采样节拍，但**当前 bitstream 烧进去是听不到有意义的声音的**。

原因是 `synth_check_top.v` 里的 I2S 输出是**占位波形**：

```verilog
assign o_hp_bck = bck;
assign o_hp_ws  = bck_en ? ~bck : bck;   // 不是真正的 I2S 声道信号
assign o_hp_din = sample_tick;           // 只是 48 kHz 方波，不是音频数据
```

DAC 收到的是**格式不对的数据**，只会产生杂音或静音。

**批次 2 的目标：把占位波形换成真正的 I2S 串行发送，并给它一个可听的音源。**

## 4. i2s_tx 设计

### 4.1 接口

```verilog
module i2s_tx #(
    parameter DATA_BITS = 24,      // 有效音频位宽
    parameter SLOT_BITS = 32       // 每声道槽位
) (
    input  wire                    clk_audio,
    input  wire                    rst_n,
    input  wire                    bck_en,      // 位周期使能（每 2 个 clk_audio 一拍）
    input  wire                    lrck_en,     // 帧起点使能（每 256 拍一拍）
    input  wire signed [DATA_BITS-1:0] sample_l,
    input  wire signed [DATA_BITS-1:0] sample_r,
    output reg                     o_bck,
    output reg                     o_ws,
    output reg                     o_din
);
```

### 4.2 时序策略

先从**已核实的官方例程参数**出发，把相位做成参数，上板后再微调：

| 项 | 值 | 说明 |
|---|---|---|
| 帧长 | **64 个位周期** | 32bit 槽 × 2 声道 |
| WS 翻转点 | 可参数化 | 标准 I2S 在帧边界；官方例程在帧内第 3/19 拍（16bit 槽时的做法） |
| 数据更新 | BCK 下降沿 | |
| 接收采样 | BCK 上升沿 | |
| 位序 | MSB 先出 | |

### 4.3 实现结构

```
   sample_l / sample_r (24bit)
            │
            ▼
   ┌──────────────────┐
   │ 槽寄存器 32bit   │  左声道：{sample_l, 8'b0}
   │ （左右交替加载）  │  右声道：{sample_r, 8'b0}
   └────────┬─────────┘
            │  每 bck_en 左移一位
            ▼
        o_din
            │
   帧计数器 (0..63) ──► WS 比较器 ──► o_ws
                     ──► bck 翻转 ──► o_bck
```

## 5. tone_src（临时音源，将来会被 A 的 audio_core 替换）

| 参数 | 值 |
|---|---|
| 输出频率 | **1000 Hz** |
| 波表深度 | 256 点 |
| 波表位宽 | signed 16 bit |
| 相位累加器 | 32 bit |
| 相位增量 | `round(2^32 × 1000 / 48000)` = **89478485** |

**接口与 A 的 `audio_core` 完全一致**（`sample_l` / `sample_r` + valid），
阶段 2 集成时直接替换，顶层其他部分不动。

**合规说明**：这是**单音正弦调试信号**，不是音频内容，不违反"严禁预录 PCM"。

## 6. 验证计划

### 6.1 仿真（`tb_i2s_tx.v`）

| # | 检查项 | 判据 |
|---|---|---|
| 1 | 复位期间 | `o_din = 0`、`o_ws = 0`、`o_bck = 0` |
| 2 | 帧长 | 一个 WS 周期 = **64 个 BCK 周期** |
| 3 | 声道分配 | WS 低 32 个位周期（左）、高 32 个（右） |
| 4 | 数据对齐 | 左声道 MSB 在 WS 拉低后的正确位置 |
| 5 | 位序 | MSB 先出 |
| 6 | 左右数据独立 | 送不同数据，验证不串道 |

### 6.2 上板（你操作）

| 步 | 动作 | 期望 |
|---|---|---|
| 1 | 接 USB，**按住 PWR 键 2 秒**开机 | 板子亮灯 |
| 2 | `gw_sh` 烧录 bitstream | 无报错 |
| 3 | 看 LED | 心跳闪 = 系统时钟在跑 |
| 4 | **耳机插 3.5mm，音量调到中等** | **听到 1 kHz 纯音** |
| 5 | 逻辑分析仪抓 `HP_BCK` / `HP_WS` / `HP_DIN` | 保存波形 |
| 6 | 示波器测 `HP_WS` 周期 | ≈ **20.83 μs** |
| 7 | 示波器测 `HP_BCK` 周期 | ≈ **325 ns**，且是 WS 的 **64 倍** |

**安全提醒**：先插耳机再上电，音量从小往大调；`PA_EN` 由 PLL 锁定控制，锁定前功放不使能。

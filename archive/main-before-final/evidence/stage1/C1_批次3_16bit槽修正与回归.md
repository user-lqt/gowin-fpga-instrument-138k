# C1 批次 3：板载 DAC 16bit 槽修正与回归

> 日期：2026-09-25
> 范围：成员 C，阶段 1 音频输出链路

## 结论

板载 DAC 实测只接受 16bit 槽格式。正式顶层已统一为：

- `CLK_DIV_SAMPLE = 256`，音频采样率约 48.0005 kHz
- `CLK_DIV_BCK = 4`，BCK 约 1.53602 MHz
- `i2s_tx DATA_BITS = 16`、`SLOT_BITS = 16`
- 24bit 音频核心样本发送前取高 16 位
- 阶段 1 临时测试音已降为 400 Hz，方便无示波器时听辨；I2S 时钟未改变

这对应 `BCK/LRCK = 32`，与板载 DAC 的官方例程格式一致。24bit 槽格式保留在 `i2s_tx` 参数化接口中，供外置 PCM5102A 等 DAC 使用。

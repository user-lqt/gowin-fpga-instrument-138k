# evidence/ —— 验收证据目录

> 验收时"代码写完"不算完成，**必须有证据**。本目录存放所有可复核的证据。

## 命名规则

```
evidence/stage0/<成员>_<内容>.<扩展名>
evidence/stage1/A_dds_单音波形_20260925/
evidence/stage2/C_端到端延迟测量_示波器截图.png
evidence/stage3/A_32路多频测试_频谱.png
```

- 阶段目录：`stage0/`、`stage1/`、`stage2/`、`stage3/`、`stage4/`
- 文件名前缀标成员（`A_` / `B_` / `C_`），避免同名冲突
- 文件名带日期（`YYYYMMDD`）便于追溯

## 每类证据的存放建议

| 证据类型 | 建议格式 | 体积控制 |
|---|---|---|
| 仿真波形截图 | `.png` | 只存关键片段，不存整段 |
| 综合 / 时序报告摘要 | `.md` 或 `.txt`（摘抄关键数字） | 不要整份报告 |
| 资源占用 | `.md` 表格 | LUT / FF / BSRAM / DSP / WNS |
| 逻辑分析仪截图 | `.png` | I2S、键盘扫描、I2C |
| 示波器截图 | `.png` | 端到端延迟测量 |
| 频谱截图 | `.png` | 多频测试模式的独立谱峰 |
| 录音 | `.wav`（短）或外部链接 | **大文件用外部网盘，仓库只放链接** |

## 禁止提交

- 原始波形数据库（`.vcd` / `.wav` 大文件）
- 完整综合报告（几百 KB 且大部分无信息）
- 任何超过 5 MB 的文件 —— 改用外部链接并在 `.md` 里说明

## 阶段对应关系

| 阶段 | 必须有的证据 |
|---|---|
| stage0 | 三个 testbench 的 PASS 输出、接口确认记录 |
| stage1 | 单音频率实测、键盘事件计数、I2S 三线波形、DAC 出声录像 |
| stage2 | 4 复音频谱、ADSR 包络波形、≤10 ms 延迟测量、30 分钟连续运行记录 |
| stage3 | 32 路多频谱峰、第二音色对比、3 维表情、效果器旁路对比、≤5 ms 延迟 |
| stage4 | 冷启动录像、完整演示脚本执行记录、故障恢复记录 |

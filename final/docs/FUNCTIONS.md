# 六页操作与图形含义

A旋转调音量，A按下切音色。B短按循环 GLIDE → FX → SONG → TEMPO → TEST → ANALYSIS。
前四页共用演奏布局，显示音色、音量、实际复音、参数、按键状态、小波形和L/R李萨如。

| 页面 | B旋转 | B长按 |
| --- | --- | --- |
| GLIDE | 0～500ms，每档20ms | 滑音开关，0ms不能开启 |
| FX | 效果量0～127 | 效果量清零 |
| SONG | 循环选择3个曲目编号 | 启动/停止指引；旋转切歌，不是长按切歌 |
| TEMPO | 40～200BPM，每档5BPM | 恢复120BPM |
| TEST | ALL/GROUP/MUTE方案 | 启动/停止持续纯音测试 |
| ANALYSIS | 选择64个分析频带 | 不新增操作 |

曲目可用性以实际曲谱有效信号为准，选择编号不等于已加载。
前四页波形取效果后左路数字信号，保留窗口min/max；首个有效采集即选量程，信号变小时等待4个采集窗口再收紧量程，使小幅波形更容易看清而不改变声音。
这4幅是采集窗口，不是保证4帧屏幕刷新。比例尺变小表示同一幅度画得更高，不是音量变大。

XY取与DAC同源、同采样点的L/R，X=L、Y=R，共用尺度。同相左右相等时显示斜直线是正常现象；左右不同相位/音高/独立效果时可出现其他轨迹，不人为加相位制造图形。

## TEST：复音验证辅助

总览显示真实FFT当前谱和已采集的全开参考，标记目标附近的放大区域；局部图显示该频率范围内细节。
目标标记用于定位，不决定峰是否存在。相邻声部也可能在放大窗口内，MUTE后窗口不必全部归零。

ALL全开；GROUP只开四分之一组；MUTE N仅关闭第N路，其他继续发声。
本包64版期望64/16/63路。ACTIVE来自引擎，EXPECT为已应用方案期望数量，APPLY及稳定信息用于区分选择和已生效状态。
稳定不等于频谱或现场验收通过。参考未就绪不能冒用预设曲线。
TEST隔离普通音符输入，纯音居中并绕过效果。外部PC逐路频谱对照才是模拟输出的验证依据。

## ANALYSIS：内部信号频谱

实时图显示左路FFT及峰值信息；标记对应B选择的频带，Hz是所选频带代表频率，不是自动测出的基频，所以不旋转B时可能一直是42Hz。
历史区域是**当前所选频带的强度随更新变化**，较早在左、最新在右，不是旧版二维全频瀑布图；切频带后应结合选择状态阅读。
强度为相对量，不是校准声压、电压或可直接宣称的dBFS。
数字PEAK/RMS和饱和/FFT状态来自内部数据，不代表模拟DAC回采。

FFT长度16384，在48kHz下长窗约341ms，hop1024约21.3ms；更频繁更新不消除长窗的时间展宽。
波形碰到绘图区边缘不等于音频削顶，数字满幅检测也不能代替模拟失真测量。

`simulation/` 的图片/动图是RTL仿真和合成激励演示，非上板实拍，播放速度不代表实际刷新率。

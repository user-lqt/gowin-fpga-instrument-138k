## 烧录后的复测

1. 人工确认选择的是新测试固件，而不是原冻结固件。
2. 暂时保留当前行信号诊断接线：CH1=A 行，CH2=B 行；
   两通道黑夹均只接公共 GND，不把地夹接行、列、电源或音频输出。
3. 在未按键状态运行示波器后停止，保存一条新记录；
   然后按住 K1，再运行并在保持按住时停止，保存第二条新记录。
4. 比较未选中行的电平、约 199.87 µs 主周期、有效低宽、
   恢复边沿与 A/B 低电平重叠。不得用旧版本记录冒充新固件复测。
5. 检查键盘单键、多键、松键行为。如果电平或行为异常，停止验收，
   可人工烧回原冻结固件。
6. 行信号可靠后，再恢复联合测量接线：
   示波器 CH1=当前列、CH2=DAC 模拟 L；
   逻辑分析仪 D0=A 行、D1=B 行、D2=当前列，所有地共 GND。
7. 在测量软件中重新选择并确认本次实际烧录的测试固件。
   新采集必须记录新哈希，重新核查扫描模型与误差预算，
   不承诺启用上拉后现有验证会自动通过。

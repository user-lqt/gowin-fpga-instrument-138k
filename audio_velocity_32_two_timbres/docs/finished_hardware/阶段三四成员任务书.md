# 赛题二阶段三四成员任务书

更新日期：2026年10月2日

我们采用两个带按压开关的EC11，阶段1、2计划和既有成果保留。阶段3交付完整演奏系统，阶段4完成键床、LED曲目指引、音质和比赛证据。每位成员按较大的功能包并行推进，包内仍保留模块测试和中间集成，不把所有风险留到最后一次合并。

## 一 目标与当前基线

平台为Tang Mega 138K。基础音频采用FPGA HDL逐样本合成，至少4个独立声部、同时发声、变调、ADSR和混音按成员A确认已完成；阶段1已经上板验证。实体24键、拓展音色与表情、最终整机延迟不推定已经验收。

成品目标为24个亚克力琴键，每键两个导电胶触点；32复音；电钢琴、风琴、小号三种可辨乐器音色，其中后两种经试听确认后锁定；击键力度、摇杆弯音、FSR全局颤音深度三个独立表情输入；另有单音连奏滑音、FPGA延迟音效、RGB屏真实波形及脱机LED曲目指引。阶段三只完成实体琴键可演奏，以及EC11_A控制音量和音色切换；滑音、弯音、颤音、MCP3008、摇杆、FSR和EC11_B功能统一放到阶段四。基础端到端延迟≤10ms，拓展目标≤5ms且确定性。团队方案不改变赛题原文；三维表情口径仍需向技术支持确认。

## 二 面板与硬件定案

| 控件或硬件 | 操作或接法 | 功能 |
|---|---|---|
| EC11_A | 旋转调节；短按切换功能或确认 | 阶段三控制总音量和音色切换；阶段四可扩展为表情/效果菜单 |
| EC11_B | 阶段三暂不启用 | 阶段四再决定用于滑音、效果或其他菜单，不作为阶段三验收条件 |
| 24键双触点 | 48触点组成8×6矩阵，48只1N4148，6列3.3V上拉 | A先闭合、B后闭合，时间差映射velocity；正确释放与和弦 |
| FSR406B | 分压输出接MCP3008 CH0；阶段四引入 | 阶段四完成焊接、零点/范围校准并映射全局颤音深度 |
| 回中电位器摇杆 | 3.3V供电，单轴模拟输出接MCP3008 CH1；阶段四引入 | 阶段四测中心、死区和左右弯音并接入整机 |
| MCP3008-I/P | 3.3V供电与参考，SPI四信号，共地及去耦；阶段四引入 | 阶段四先独立测试，再接入真实系统 |
| RGB666 800×480屏 | 保留B已有显示设计，C确认时钟/跨域/管脚 | 音量、音色、菜单、模式、键状态、表情和真实音频波形 |
| 琴键LED及驱动 | C选定可用驱动器和信号，B输出24位指引数据 | 脱机曲目目标键提示，不参与琴键事件判定 |

双EC11共6路GPIO，ADC另需4路数字信号；不含屏幕、键盘、LED和调试。C必须先核对完整空闲管脚和电压，不能凭上述数量假定接头够用。洞洞板无需强制购买PMOD转接模块，但应使用可靠排针/连接器、编号线束和固定支撑。两触点需机械行程差和独立限位，不能靠软件制造虚假力度。

当前MCP3008、双向回中摇杆和FSR均未到货，且按团队决定统一放入阶段四。阶段三不建立这些硬件的整机依赖，A/B/C先完成24键琴键、可演奏音频、EC11_A音量/音色控制和基础系统稳定性；阶段四再单独开启传感器、滑音、弯音、颤音及EC11_B任务。

## 三 开工前共同冻结事项

这是一轮共同确认，不另立漫长阶段。C提供已上板工作系统的提交号、采样率、音频时钟、每样本可用周期和完整管脚表；A/B对照同一版接口实现。以下为建议协议，需A/B/C确认后由C更新common及接口文档，本任务书本身不修改RTL接口。

| 字段 | 建议语义 | 确认或维护人 |
|---|---|---|
| PARAM_VOLUME 0 | 0至65535，A处理唯一总增益并做平滑；静音仍处理NOTE_OFF | A/B/C |
| PARAM_INSTRUMENT 1 | 建议0电钢琴、1风琴、2小号；切换仅影响新音符，旧声部保留原音色 | A/B |
| PARAM_PITCH_BEND 2 | 16位符号扩展的-8192至8191，默认中心0，建议范围±2半音 | A/B |
| PARAM_MODULATION 3 | 0至65535，控制颤音深度；建议固定约5Hz LFO，最大深度经试听标定 | A/B |
| PARAM_EFFECT_MIX 5 | 0至65535干湿比例，0为干声；由C接收处理，不被A丢弃 | B/C |
| PARAM_GLIDE 6 | 建议0关闭且使用复音模式，1至500表示毫秒并启用单音连奏；越界钳位 | A/B/C |
| 音频与键状态 | 保留24位音频语义；24位key_state及屏幕状态更新需版本化，不覆盖旧16位接口而不通知 | B/C |

滑音关闭时B发送0并保存上次非零时间；开启时恢复保存时间，建议默认100ms。跨模式切换由A显式清空/释放旧分配并重建已按键状态，B提供可靠键状态或重新发音机制；团队必须选定一种握手，防止挂音，不暗用保留参数。

复位默认电钢琴、适中音量、无弯音/颤音、滑音关闭、效果干声；具体默认数值共同冻结。音频输出位宽适配沿用C实测可靠链路，不以任务书强制更换DAC协议。事件拥塞策略需确保NOTE_OFF不被静默丢弃，并能诊断溢出。

## 四 阶段三任务包

### A3 阶段三基础声音与演奏

A仅修改rtl/audio_core及sim/audio_core_tb；本地编译、自检testbench、仿真波形和音频分析由A负责，Gowin综合、时序及上板由C负责。

在现有A2上扩展阶段三需要的可演奏能力，保留独立相位、包络、混音饱和和现有复音基础。完成电钢琴、风琴、小号三种音色的选择接口和可听辨切换；EC11_A发送音量或音色参数。阶段三不实现滑音、弯音、颤音，也不等待MCP3008、摇杆和FSR。

后续升级目标确定为64复音，不替代本轮32复音交付。A将声部数、分配索引、循环上限、包络存储和混音余量按可配置规模规划；C在32复音稳定后评估64声部的每样本运算预算、资源和时序。现有active_voice_count[5:0]不能表示64，升级前由C协调扩为至少7位，并同步A/B/C接口、UI、测试及版本文档；本轮不提前改公共接口。64复音需验证64独立声部同时输出、第65音符抢占、全部释放及最大负载时的采样截止时间，不以参数配置为64代替验收。

阶段三只处理音量平滑、音色切换、重复音符、声部抢占、NOTE_OFF和复位。摇杆连续弯音、FSR控制的LFO颤音深度、单音连奏滑音及其模式切换全部列入阶段四。多频测试入口独立于24实体键，能够激活32个不同频率的声部；不同谐波不冒充独立声部。

交付RTL、testbench、运行命令、PASS记录、波形/可试听音频、频率与包络检查、声部状态和算法说明。阶段三回归覆盖24键事件、32声部目标、超额第33音符、全释放、力度两端、音量调节、三音色切换和最大混音；弯音、滑音、颤音测试移至阶段四。Questa独立复验是否恢复由成员A确认，未运行就注明；Icarus结果不称为Questa结果。

### B3 完整演奏面板

B在rtl/input、rtl/ui、sim/input_ui_tb完成24键双触点、实体键床、EC11_A、菜单和RGB页面数据。阶段三只让EC11_A控制音量和音色切换；EC11_B暂不启用。阶段三不接入MCP3008、FSR和摇杆，弯音/颤音/滑音接口不纳入阶段三硬件验收。

重点验证触点A/B在同一扫描帧确认、最快击键、B先A的异常次序、触点抖动、和弦与释放。修正可能因旧ab_age造成的同帧漏NOTE_ON；不能把未检查的现有24键代码直接认定可用。力度时间差映射应单调，避免过长消抖破坏动态和延迟。

阶段三仅对EC11_A消抖与解码，短按只切换一次音色，旋转只调音量；EC11_B不发送事件。屏幕与真实参数同步，显示24键而不是截断成旧16位。ADC、摇杆、FSR的滤波和校准属于B4。

交付RTL、测试脚本、事件/参数波形、菜单表、单键标定方法、24键实体接线记录和阶段四扩展接入需求。基础4×4键盘旧测试不能替代新24键与EC11_A回归。

### C3 完整扩展系统

C维护rtl/system、rtl/common、project、constraint及系统仿真，从团队确认的可靠系统版本集成，不让旧分支的系统文件覆盖已验证I2S链路。

同包完成A/B连接、事件队列与EC11_A参数路由、跨时钟域、屏幕数据交接、可旁路FPGA延迟效果及干湿混合、音频波形显示和性能计数。阶段三不接入MCP3008、摇杆和FSR，C只完成阶段四所需的扩展接口预留和管脚规划；EC11_B不作为阶段三功能。效果反馈须限幅且系数稳定，旁路不改变基础音频节拍；总音量由A处理，C不重复施加同一增益。

开发期间运行必要的Gowin综合与时序检查，最终阶段三统一验收时确认最大负载下赶上每样本截止时间。上板记录采样率、资源、最坏端到端延迟及波动，计入扫描、消抖、事件、跨域和DAC；不能用平均延迟或音频固定采样率代替整机证据。

交付最终管脚表、接口版本、系统testbench、构建工程、bitstream、综合时序和板级测量记录。基础版≤10ms、拓展≤5ms分别判定，指标失败就记录限制并定位。

## 六 阶段四任务包

### A4 音质和可复现证据

优先精修电钢琴，使轻弹与重弹不仅音量不同，起音亮度也有可闻变化。对三音色做等响度比较，调整各音区、力度曲线、释放和抢占平滑，处理弯音/颤音/滑音噪声。保留32声部多频、频谱和实际活跃振荡器数量证据，提交与最终版本对应的回归。资源和时序证据由C提供，A解释合成算法与运算量。

### B4 实体键床和LED曲谱

单键样机测试通过后复制24键，安装独立机械限位和面板双旋钮，完成阶段三键床固定、全键校准、长按释放和多键演奏。EC11_A在阶段三安装并接入；EC11_B、摇杆、FSR和MCP3008属于阶段四，阶段三只预留安装位置和连接器位置；力度不足时先修机械行程差，不用固定velocity伪装检测。

实现至少一段可重复展示的脱机曲谱、节拍与24位LED指引数据，明确暂停、重启和演奏模式切换。指引不替代真实按键采集，不凭灯亮自动播放预录音频。完善最终屏幕状态与错误提示。

### C4 电气驱动和整机冻结

确定LED驱动方式、限流与供电，集成B的指引逻辑；阶段三完成键盘、屏幕、EC11_A、音频链路和基础系统约束。EC11_B、MCP3008、摇杆和FSR的电源去耦、共地、连接器防错、线束固定、管脚和最终约束统一放在阶段四。

上板完成冷启动、多次复位、连续运行至少30分钟、最大声部/效果负载和端到端延迟测试，留下与最终bitstream一致的综合时序报告。打包从零构建/下载步骤、现场演示脚本、备份bitstream和已知限制；验收后冻结stage4-final。

### 9.2 A3 文件、模块和测试

**代码边界**

- 只修改 `rtl/audio_core/` 和 `sim/audio_core_tb/`，除非接口冻结后由C协调修改 `rtl/common/`。
- 不修改键盘扫描、EC11解码、Gowin顶层、管脚约束和I2S发送模块。
- A不直接读取EC11引脚，只接收B打包后的参数事件。

**实现顺序**

1. 将现有4声部状态扩展为32个可独立分配的声部槽位，保留每声部的音符、相位、频率、包络、音色和活动状态。
2. 完成声部分配：空闲槽优先；无空闲槽时建议按释放态、包络幅值、最早触发时间选择抢占对象，具体规则形成文档。保持音符事件原始顺序，拥塞时保护NOTE_OFF或执行明确的失效静音恢复，不重排同一音符的按下与释放。
3. 完成三种音色的独立合成路径或参数组。电钢琴优先保证起音和衰减听感，风琴保证持续谐波，小号保证起音亮度和音色差异。
4. 完成力度到起音增益及起音亮度的映射；阶段三不使用摇杆、FSR或滑音参数。
5. 完成总音量平滑、音色切换规则和混音饱和；建议音色切换只影响新触发声部，已有声部保持原音色，避免切换瞬间爆音。
6. 提供独立多频测试入口，能够在没有24键硬件的情况下激活32个不同频率的声部，用于C测资源和频谱。

**A3 必测用例**

| 编号 | 激励 | 通过条件 |
|---|---|---|
| A3-01 | 32个不同note_id连续NOTE_ON | 32个声部均有独立活动状态、相位和频率 |
| A3-02 | 第33个NOTE_ON | 按既定抢占规则替换一个声部，不死机、不产生X态 |
| A3-03 | 32声部同时NOTE_OFF | 所有声部进入释放并最终静音，无挂音 |
| A3-04 | 同一音符快速重复按下 | 按冻结的重触发或叠加策略运行，无错误释放、异常增益或挂音 |
| A3-05 | 三个PARAM_INSTRUMENT值 | 三种音色输出可区分，编号越界回退到电钢琴 |

## 十 阶段四详细执行清单

### 10.1 A4 音频扩展

- 滑音：单音连奏模式，定义开启、关闭、时间单位和断音行为；退出后不得影响普通复音。
- 弯音：接收摇杆中心校准后的有符号值，设置死区、最大音程、回中速度和音高平滑。
- 颤音：接收FSR映射后的深度值，固定LFO频率或冻结可调范围，深度变化不得产生明显阶梯噪声。
- 处理EC11_B传入的扩展参数，但A不读取EC11_B物理引脚。
- 回归滑音、弯音、颤音与32复音同时运行的最大负载。

### 10.2 B4 传感器和扩展控制

- MCP3008先在洞洞板上独立验证，再接入顶层。
- FSR分压记录松开零点、轻压、中压、满压及回零时间，建立校准表。
- 摇杆记录中心值、左右端点和死区；中心偏移不得造成持续弯音。
- EC11_B先确定一种主功能，不同时塞入多个难以演示的菜单。
- 所有连续参数增加限幅、滤波、变化阈值和发送频率限制，避免参数事件洪泛。

### 10.3 C4 硬件和最终验收

- 核对MCP3008、摇杆、FSR的3.3V供电、共地、去耦和SPI电平。
- 核对EC11_B、ADC、LED、屏幕和键盘不发生GPIO冲突。
- 对传感器做独立SPI波形、通道切换、噪声和断线测试，再接入整机。
- 完成最终线束编号、连接器防呆、洞洞板固定和上电检查。
- 在最大声部、效果和表情负载下重新测资源、时序、延迟和连续运行。

## 十一 阶段三阶段门检查表

阶段三只有在以下项目全部有证据时才算完成：

1. 24键实体琴键全部接通，单键、快速连击、释放和至少四键和弦通过。
2. EC11_A能稳定调节音量并循环切换三种音色。
3. A的32声部测试通过，能解释声部状态、抢占和释放。
4. 三种音色在相同音高和相近响度下可听辨。
5. 复位、NOTE_OFF、混音限幅和I2S回归通过。
6. C完成综合、时序和基础上板验证，留下延迟和资源记录。
7. 阶段三不把EC11_B、滑音、弯音、颤音、MCP3008、摇杆、FSR写成已完成。

阶段三任一硬门槛不满足，回退到stage2-baseline定位；不得用“16声部通过”“两种音色可用”作为阶段三通过理由。

## 十二 阶段四测试与交付要求

### 12.1 A4 参数处理和测试

### 12.2 B4 输入与校准测试

MCP3008驱动负责SPI事务和通道轮询，滤波模块负责有效读数和异常标记，映射模块负责生成标准参数；分开测试这三层。先仿真通信时序和测试数据，随后由B/C一起核对实物波形。FSR和摇杆校准参数应可复位或重标定，不能将一只器件的中心值硬编码到所有样机。

| 编号 | 测试动作 | 预期结果 |
|---|---|---|
| B4-01 | CH0/CH1交替读取及已知电压测试 | 通道不串，读数与参考电压一致；边界值不翻转 |
| B4-02 | 摇杆静置、左右拨动、松手 | 校准中心稳定，死区内输出0，松手回中 |
| B4-03 | FSR松开、轻压、重压、松开 | 零点及范围可记录，深度单调，松开回零 |
| B4-04 | 叠加噪声、端点饱和和输入不更新 | 滤波/钳位生效，诊断明确，不形成参数洪泛 |

| B4-06 | 弯音与压力同时操作并演奏和弦 | 两输入独立，音符事件顺序和释放不受连续参数影响 |

### 12.3 C4 整机测试和交付

阶段四按供电检查、ADC独立测试、输入参数检查、A4集成、LED驱动、全系统压力测试的顺序操作。LED器件、驱动方式、限流和功耗未确定前不焊最终板；屏幕与LED刷新不能拖慢I2S或事件队列。

# 当前成品计划与任务入口

本目录只维护一套当前安排。阶段三一次完成32复音、三种音色、24键实体可演奏和EC11_A音量/音色控制；阶段四再完成EC11_B、MCP3008、摇杆、FSR、滑音、弯音、颤音及成品验收。64复音为后续升级目标。

## 阅读顺序

1. [总计划书](../高云FPGA电子乐器项目总计划书_最终版.md)：团队目标、阶段门、集成和证据要求；阶段一、二原文保留。
2. [阶段三四成员任务书](阶段三四成员任务书.md)：A/B/C详细执行清单与测试编号，是当前阶段任务的唯一详细源。
3. [要求完成情况](requirements_completion_status.md)：区别已完成、待实现、待硬件实测，不以规划代替成果。

三份旧个人任务书继续提供职责边界和阶段一、二历史；其中阶段三、四已转为当前详细执行源的入口，不能再按旧的触摸/16声部方案开工。

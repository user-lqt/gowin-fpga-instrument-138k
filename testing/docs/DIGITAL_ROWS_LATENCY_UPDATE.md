# 数字行列联合延迟分析更新

## 更新内容

联合模式不再先运行仅示波器的 B 脉宽推断，也不再要求至少五个单触点脉冲。
数字 B 行与列共同有效的内部窗口用于定位首次持续有效 B 扫描；
共同列用于两台仪器的全起止沿配对；CH2 独立进行 18 项模拟起音分析。

零个或少量单触点脉冲可以进入验证，但不保证可用。对齐前提是人工确认同一次单键按压，
并且两份记录都保留首次主列导通前静止段。错帧配对须残差超限或与另一记录已观测静止段冲突，
不能只凭周期波形宣称同步唯一。

缺行、扫描缺帧、无法解释的部分导通、错位、静止段不足、原始哈希不符等仍拒绝输出可用结果。
手动示波器模式保持原分析条件，不会因这次更新自动具备数字行信号。

## 下一次操作

1. 关闭旧软件，重新从当前“测试软件”文件夹启动。
2. 先用 K22 一次联合采集验证，不要立即重测整轮；不需要故意慢按。
3. 核对接线：示波器 CH1 与逻辑 D2 同接第 4 列 A15；CH2 接 DAC 模拟 L；
   逻辑 D0 接 A 行 A14，D1 接 B 行 A13；仪器地仅接已确认公共 GND。
4. 上述为 FPGA 球位，不是排针编号。按当前工程约束核对，不猜测物理位置，断电调整并联接线。
5. Logic 2 保持运行并开启 Automation Server。按键延迟页选择“自动联合测量”，仅选 K22，
   选择实际烧录文件和原有测量条件，累计目标先设 1。
6. 示波器预留按下前数毫秒基线及完整起音，CH1 下降沿触发，启动前 STOP。
   勾选联合接线确认后点击“开始联合测量”；软件会启动逻辑采集并发送 SINGLE。
7. 等置顶提示“现在按一次 K22”再正常按一次，按住至提示采集已停止。
   不用手动导出或选择 CSV，不要重复按键。
8. 等保存、联合分析结束。误差预算无依据时留空，结果只用于观察，不填零或随意放宽来获得通过。

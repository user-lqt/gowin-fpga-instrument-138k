## 现场版本的放行条件

以下仍需真实仪器端到端验证，不能用增加合成测试替代：

1. 固定烧录文件、软件版本、仪器接线和参数，不在现场临时放宽判据。
2. 在同一冻结版本上验证代表键及正常不同按压速度，不为通过而改变按法。
3. 完整走通开始采集、提示按键、停止、下载、报告和重启后继续统计。
4. 验证未连接、触发超时、采集中断、分析不适用时不会显示“通过”或丢失原始文件。
5. 固定最终起点口径和有依据的误差预算；报告明确 B 扫描窗口不是物理闭合瞬间。
6. 验证范围及失败样本均记录，未覆盖情况不宣称已保证。

## 现场出现异常时

- 不连续重按、不重复下载同一 STOP 波形来充数，不现场临时改阈值获得通过。
- 先保留原屏、两路原始数据、完整数字 CSV、关联清单和失败诊断。
- 按异常类别处理连接/采集问题或分析不适用，不把“无法分析”说成“延迟超标”。
- 预先归档的可复核报告和原始数据可以作为补充证据，但不能冒充本次现场实测，
  也不能替代评委要求的现场验证。
- 若实时分析不可用，应如实说明并按现场允许的方法验证，不能承诺已有离线报告必然替代现场测试。

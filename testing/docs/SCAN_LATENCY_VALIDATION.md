# 行列联合延迟验证

## 接线与采集

以 K1 为例：示波器 CH1 接 B16 列、CH2 接 DAC 模拟 L；逻辑分析仪 D0 接 E14（A 行）、D1 接 E13（B 行）、D2 接 B16（列）。所有仪器地只接已确认的公共 GND，断电并联接线，不拔原线。K2～K4 的列依次为 B15、A16、A15，A/B 行不变。以上为 FPGA 引脚名，不是排针序号。

两台仪器先开始记录，再只按一次目标键，最后停止并保存。同次记录必须覆盖首次列导通前静止段、B 导通及至少三个连续有效 B 扫描窗口，数字完整扫描还须覆盖示波器列记录及模拟起音。按下前静止段至少两个扫描周期；为起音基线分析，建议多留数毫秒。仅按目标键，避免其他键或自动演奏干扰。

支持 Logic 2 自动化采集，也保留离线导入。不要把两次不同按键的记录拼在一起。

## 自动联合采集

Logic 2 需运行并开启 Edit → Settings → Enable Automation Server，地址 127.0.0.1:10430。软件通过本地接口控制；Python 需要已安装 logic2-automation。连接与采集是否成功，以本次真实设备检测、保存文件及联合分析结果为准，不使用模拟设备代替。

1. 打开“按键延迟”单页，顶部选择“自动联合测量”。当前目标下方“联合接线”勾选确认；可先点“检测逻辑分析仪”，此按钮不采集。“误差预算与采样设置”默认收起，数字采样率默认请求 24 MHz；页尾“离线联合复核”仅供已有记录使用。
2. 示波器设为 CH1 下降沿边沿触发，阈值 0.5～2.5 V；设置足够的触发前静止段及音频起音窗口，最后 STOP。
3. 在同一页建立按键/次数计划并确认实际固件。
4. 点击“开始联合测量”，确认允许启动两台仪器。软件先开始 D0/D1/D2 数字记录，再向示波器发送 SINGLE。看到“现在只按一次目标键”提示后再按键，保持至保存开始。
5. 示波器触发后自行 STOP，软件停止逻辑采集，保存 .sal 会话和 digital.csv，再下载示波器原屏与两通道 RAW，自动关联并分析，不需要手工导出或选择 CSV。等待按键触发超过 15 秒会取消本次并尝试停止自己启动的采集。

高级设置的误差预算可以留空，不阻止联合采集和扫描观察。留空时报告只给观察结果，明确不判定 5 ms 达标，JSON 中上界和达标判定为 null。待误差依据核实后可使用保留的记录重新分析，无需为补参数重新采集。

Logic 原始文件位于 `measurements/raw/logic/logic_001` 等递增目录；
示波器原始记录在 `measurements/raw/latency`，其中 `joint_capture.json` 使用相对于该记录目录的路径引用逻辑文件。
联合报告在 `measurements/reports/latency/同记录编号/scan_validation`。
失败记录保留，无法自动导出的逻辑会话尽可能保存在 capture.sal，导出失败时保留 Logic 中会话用于人工恢复。

自动采集会明确改变示波器运行状态（SINGLE，失败清理时 STOP），不改触发阈值、量程、引脚或 RTL。只有点击并确认“开始联合测量”才执行这些动作。启动软件、检测逻辑分析仪、离线分析均不启动采集。

### 未进入等待状态时

发送 SINGLE 后，软件短暂轮询状态，允许刚启动时仍读到旧的 STOP。
只有观察到 WAIT/RUN 后才提示按键；始终 STOP 或提示前已触发会保留失败记录并退出，
不会自动再次发送 SINGLE。此时应先查看错误，不要连续按键或重复点击。
释放所有琴键，核对 CH1 确实接目标列、触发为 CH1 下降沿、阈值处于高低电平之间，
并人工观察空闲状态是否已有下降沿或噪声触发。
`measurements/raw/logic/logic_编号/capture.json` 保存失败原因、阶段与启动状态序列；
失败时尽可能保留 `capture.sal`，但不能作为已完成的联合测量或达标证据。

## 数字数据格式

支持 UTF-8、逗号分隔、有表头的数字 CSV，时间单位为秒，各数字列为 0/1；既支持均匀采样，也支持 Logic 2 的变化时刻 CSV。例如：

```csv
Time [s],Channel 0,Channel 1,Channel 2
0.000000000,1,1,1
0.000000042,1,1,1
```

上述仅为格式示例，不是实测数据。实际文件必须覆盖足够的完整扫描周期。页面可以手填真实表头名称。变化时刻 CSV 必须提供真实采集采样率，不能把相邻变化时间之差当采样分辨率；不会通过插值伪造采样精度。不支持协议解码 CSV。

## 软件步骤

1. 打开“按键延迟”，展开页尾“离线联合复核”，从 `measurements/raw/latency` 中选择同次示波器记录的 `trial.json`。
2. 选择同次逻辑分析仪 CSV，核对时间、A、B、列的表头映射。
3. 填写经核实的额外起音/分析余量（微秒）及示波器时基误差预算（ppm）。没有已知依据时留空，仅输出观察报告，不应随意填写以获得通过结果。
4. 确认同次记录、接线及起点口径，再生成报告。

报告保存在 `measurements/reports/latency/同记录编号/scan_validation/verification_001` 等递增目录，
含导入 CSV 副本、analysis.json、B 窗口放大图和中文 report.html。不覆盖以前联合验证记录。离线分析不修改仪器设置。

## 判断边界

数字验证区间固定为首个完整主列导通前 5 ms 至数字记录末尾，不寻找任意可通过片段，不裁剪按下后异常。
首个主列脉冲前若有超过 1 µs 的其他列导通，或记录起始列低，拒绝截取。
完整数字 CSV 保留，报告列明未验证的远端等待前缀；区间内异常检查不变。
对该区间的扫描验证不能证明此前长等待段无短跳变，也不能证明未来扫描不会暂停。

使用完整列信号的下降/上升边沿共同拟合两台仪器的时间关系。新版以人工确认的同一次单键按压及两份记录共同包含首次主列导通前静止段为对齐前提，不再要求列波形存在至少五个单触点脉冲。零个或少量单触点脉冲也可进入联合验证，但并不保证结果可用。

程序检查 ±1、±2 帧错位：若错位残差仍合格，必须确认它会在另一台仪器已观测的按下前静止段中引入列导通，才能排除该错位。不能只凭周期波形宣称同步唯一。若静止段、首次导通、行扫描或完整列边沿不满足条件，仍拒绝计算。逻辑分析仪允许多余尾部扫描脉冲，时间映射比例和最大残差均记录在报告。

B 定位直接检查数字 B 行内部窗口与列持续低，至少保持三个连续有效窗口；不先调用仅示波器的 B 脉宽推断。独立模拟起音分析从首次主列导通后搜索，不使用猜测的 B 点作为搜索门槛；采用两种滤波、三种采样率、三种阈值共 18 项配置的最晚起音。若起音不在 B 窗口之后，或记录不完整、B 行缺失、存在未解释部分导通等情况，仍拒绝输出可用结果。

联合采集保存示波器原屏、两路原始数据、音频频谱，并直接进入数字行列联合分析，不再先产生一个“单触点脉冲不足”的仅示波器失败提示。手动示波器模式仍保留原来的脉宽推断条件，不能用它代替行列测量。

新版 `analysis.json` 内 `analysis_model_version=digital_rows_v5`，`audio_evidence` 保存原始哈希、首次主列导通、18 项起音配置与结果。中文报告直接包含这些明细，不要求另有仅示波器推断报告。重复验证创建新的编号目录，保留旧证据。联合分析可用次数与仅示波器条件性分析仍分别统计；同一原始记录的多份报告不重复计次。

### 首次 A 窗口接触瞬态

v4 对以下情形单独分类，不扩大常规 2 µs 边界排除带：

- 仅限同一次按压已人工确认的联合记录，且初始短低段确实超出旧列边界规则。
- 首个完整主列脉冲之前的所有短低段均不超过 1 µs，全部在同一个首次 A 独占窗口内部；
  两端仍排除 2 µs，不允许其它帧、B 窗口或窗口外事件混入。
- 首个主列脉冲须终止于该 A 行尾部附近，紧接着的 B 内部窗口必须列高；
  不用此分类恢复同时 A/B 导通或 B 部分导通记录。
- 首次下降沿改为 A 窗口区间约束，而非精确同步点；首次上升沿与后续所有完整起止沿
  继续参与同一残差限制下的拟合。模拟列的早期低段也须独立落在同一 A 窗口。
- 错帧检查使用相同的首次下降沿区间处理，不能在反例中恢复更严格的旧规则来制造唯一同步。
- 保留全部原始事件，单独保存 `initial_a_contact_transient` 明细，与普通边界短跳变计数分开。

这属于“初始 A 接触区间”的分析模型，不认定电气噪声、真实机械抖动或精确物理闭合时刻。
未满足条件时仍拒绝分析；不影响 B 内部、缺行、错误相位或后续边沿错配的拒绝。

### 首次 B 窗口中途导通

v5 新增 `midwindow_b_v1`。此模型与初始 A 瞬态独立，不是扩大边界排除带：

- 两仪器记录已人工确认同一次按压，行周期、相位、完整共同列边沿对齐和错帧检查均通过。
- 仅首次有 B 导通证据的窗口允许中途开始；此前至少有两个 B 窗口证据。
- 低段开始于 B 内部且 A 尾部已经退出；原始数字 B 内部恰有一个低段，
  从中途开始保持到末尾，结束沿在该 B 行尾部的原有边界带内。
- 示波器原始列电压在该下降沿前须有独立高段、下降沿后须有独立低段；
  仅避开原有全局拟合容差覆盖的边沿区间，不用形态学填补生成这两个证据段。
- 随后连续三个完整 B 内部窗口列低。首次低段中途断开、后来再次部分导通、
  后续缺窗、模拟证据不符或 CSV 错配，均不通过此模型。
- 独立低段仍须通过原有主列脉冲宽度规则；1～10 µs 的独立脉冲不自动恢复。

计时零点仍为首次有 B 证据的扫描窗口起点，不挪到下一完整窗口，也不挪到窗口内的下降沿。
保守闭合参考仍使用前一 B 窗口起点，原有扫描、采样、同步和边界余量不减少。
`b_midwindow_contact` 保存首次部分窗口、观测低段起点、模拟高低证据区间及随后三个完整窗口。
中文报告新增原始模拟列电压与数字行列对照图 `b_midwindow.png`。

列低段的阈值起点不等于精确物理闭合。该模型仍依赖同一次按压确认和持续有效导通口径，
不是机械触点首次瞬时接触测量，也不填补尚未核实的误差预算。

检测的是第一次 B 行低且列低的扫描窗口，不声称获得精确 FPGA 采样边沿。保守闭合下界取前一次 B 扫描窗口起点，再加入对齐、采样分辨率、人工分析余量和时基误差。模拟起音取已有多方法、多阈值分析中的最晚值。

上界小于 5 ms 仅支持**本次记录、B 持续有效导通口径及已填写误差预算**下的条件性结论，不证明首次瞬时接触、全键最坏情况、无抖动或未来扫描永不暂停。实测最大周期仍需当前 RTL 的固定扫描逻辑佐证。

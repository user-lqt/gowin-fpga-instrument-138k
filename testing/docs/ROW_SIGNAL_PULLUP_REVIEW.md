## 5. 整合和上板复测顺序

1. 整合任务确认当前生产版本与矩阵电路适用该修正后，仅合入八项行上拉，
   保持低有效/未选中三态策略，不改引脚、消抖和音频。
2. 重新综合、布局布线并确认实际物理 I/O 属性和时序报告，保存新固件哈希；
   老 `.fs` 不会因修改 CST 自动更新。未经用户确认不烧录。
3. 烧录确认后的新版本，先保持本次 A/B 行示波器接法，分别采集未按键、
   K1 按住两种状态，核查主周期、低宽、恢复边沿和 A/B 重叠。
   这些是新的状态对照，不覆盖 `row_scope_001/002`。
4. 若未选中行稳定恢复高电平，再核查多键扫描及触点行为；
   若边沿仍过慢或负载影响明显，先复核实际电路与探测负载，
   不直接用预期上拉电阻值或增大软件容差来放行。
5. 信号可解释后再恢复联合接线：示波器 CH1=列、CH2=DAC 模拟 L，
   逻辑分析仪 D0=A、D1=B、D2=列，所有地只接公共 GND。
6. 重新核查软件扫描模型。当前模型的固定低宽、无重叠与同步残差约束，
   需要由新实测确认；不能承诺启用上拉后不修改模型就必然通过。
7. 重新进行同次按键联合采集，再计算扫描余量和模拟起音；保留阈值、
   时钟误差及其他预算，不把固定理论 200 µs 当作无条件最大扫描间隙。

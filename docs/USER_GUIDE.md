# 演奏与界面操作

## 双EC11与六页

EC11_A旋转始终调音量，短按切换钢琴、吉他、编钟。EC11_B短按循环 `GLIDE → FX → SONG → TEMPO → TEST → ANALYSIS`。

| 页面 | EC11_B旋转 | EC11_B长按 |
| --- | --- | --- |
| GLIDE | 滑音时间0至500ms，每档20ms | 开启/旁路；0ms不能开启 |
| FX | 延迟效果量0至127 | 归零 |
| SONG | 选择3个曲目槽 | 启动或停止当前指引 |
| TEMPO | 40至200 BPM，每档5 | 回120 BPM |
| TEST | ALL、GROUP或指定MUTE | 开始/停止复音测试 |
| ANALYSIS | 选择64个分析频带 | 无新增功能 |

前四页共用演奏布局，显示音色、音量、实际声部、参数、琴键、波形和XY。TEST与ANALYSIS是专门页面。键盘实际按下数不必等于活跃声部数：释放包络或尾音仍可能继续占用声部。

## 正常演奏

按下同一琴键时，两个触点闭合间隔越短，映射力度越大；力度同时影响音量、音色亮度与起音。最终代码已有逐键映射表，不应继续用早期统一1秒阈值解释当前行为。K22保留了临时响应修正，是否完成实物标定应由实际记录说明。

摇杆改变音高表情，FSR压力控制颤音；进入GLIDE页启用滑音后，用已验证的连续音符方式试听过渡。FX是硬件延迟效果，不把它笼统描述为混响、合唱或所有效果器。

## 本地曲目与LED

1. EC11_B短按到SONG，旋转选择槽1、2或3。
2. 槽1为《茉莉花》简化练习，槽2为《小星星》练习；槽3为手机上传的曲谱。
3. 本地长按启动；自由模式按对当前物理琴键后推进，连续重复音需要松开重按。
4. 完成后24个映射灯亮起；退出SONG灯灭，再进入后需重新启动。
5. 第三槽未上传时不可用；上传曲谱、映射与事件记录均为RAM状态，复位或掉电后清除。

手机可选择自由/节奏练习与BPM。自由模式按对推进；节奏模式有四拍预备、拍点闪光与GOOD/LATE/MISS等反馈，随后按时值推进。LED按物理键号指引，修改音符映射不会移动LED位置，但会改变实际曲调。

当前源码仍含历史上传限制：`instrument_link.v` 对C1键号6返回参数错误，历史网页协议也拒绝6。这是对现有代码的记录，**不表示K6实体键不可演奏**；本次按用户要求不改最终RTL或网页程序。第三槽曲谱若含K6将被原协议拒绝，不能在说明中写成已支持全部24键下载目标。

## TEST复音验收

- ALL：64个声部同时输出不同频率。
- GROUP：只开四分之一组，16个声部。
- MUTE N：只关闭指定声部，剩余63个。
- 页面区分已选择、已应用方案与稳定状态；ACTIVE来自引擎，不是固定标签。
- 测试隔离普通音符，纯音居中，绕过FX；退出后回到演奏。

全开参考谱需要实际采集，不能把未就绪的预设图当作测量。模拟输出验证需同时观察ALL与对应MUTE目标峰。

## 波形 FFT与XY

波形自动缩放用于提高小信号可见度，曲线越高不直接代表实际音量越大。FFT采用16384点，长窗导致分析响应展宽；不以显示延迟推断音频延迟。

ANALYSIS上的Hz随所选频带变化，不是自动测出的琴音基频。幅度为内部相对量。XY使用同步L/R，左右相同时呈对角线正常，不要求任何声音都出现椭圆。

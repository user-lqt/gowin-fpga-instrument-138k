# 操作说明

EC11_A旋转调音量，短按切换钢琴、吉他、编钟。EC11_B短按循环切换六个页面。

| 页面 | EC11_B旋转 | EC11_B长按 |
| --- | --- | --- |
| GLIDE | 滑音时间0–500ms，步长20ms | 开启/旁路，0ms时不启用 |
| FX | 延迟效果量0–127 | 归零 |
| SONG | 选择曲目槽1–3 | 启动/停止指引 |
| TEMPO | 40–200 BPM，步长5 | 恢复120 BPM |
| TEST | 选择ALL、GROUP、MUTE | 开始/停止测试 |
| ANALYSIS | 选择64个分析频带 | — |

## 演奏

双触点闭合间隔越短，力度越大；力度同时影响音量、泛音与起音。摇杆控制音高表情，FSR压力控制颤音。GLIDE开启时，连续音符可产生滑音；FX调整延迟效果。

## 曲目指引

1. 进入SONG，选择槽1《茉莉花》、槽2《小星星》或槽3下载曲谱。
2. 长按启动，也可由手机发送选曲命令。
3. 自由练习按对当前目标键后推进；重复音需松开后重按。节奏练习按曲谱时值推进，含四拍预备及GOOD/LATE/MISS反馈。
4. 完成后24个指引灯亮；退出SONG灯灭。再次进入需重新启动。

第三槽、键位映射和演奏记录均存RAM，掉电清除。下载格式和操作见[蓝牙与手机](BLUETOOTH.md)。

## 复音测试与分析

TEST中ALL开启64个独立频率声部，GROUP开启16个，MUTE关闭指定一个、保留63个。测试使用居中纯音并绕过FX，期间隔离普通演奏输入。ACTIVE显示引擎实际活跃声部；释放尾音也可能占用声部。

波形自动缩放，图形高度不能直接比较实际音量。ANALYSIS的Hz为所选FFT频带代表频率，幅度为内部相对值。XY横纵轴为同步左右样本；左右相同呈对角线。

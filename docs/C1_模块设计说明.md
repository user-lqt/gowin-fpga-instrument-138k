## 1. 本阶段要达成的目标

**一句话**：让 FPGA 自己产生的固定正弦波，经过 I2S 送到板载 DAC，从耳机口稳定出声。

对应任务书 C1 的硬性门槛：

| # | 门槛 | 怎么证明 |
|---|---|---|
| 1 | LRCK（HP_WS）实测 **48 kHz** | 示波器测周期 ≈ 20.83 μs |
| 2 | BCK = 64 × LRCK，DATA 对齐无错位 | 逻辑分析仪抓三线 |
| 3 | 左右声道稳定、无杂音/爆音/周期性中断 | 听 + 长时间观察 |
| 4 | 有逻辑分析仪波形证据 | 存 `evidence/stage1/` |

**本阶段不做**：不做合成、不做复音、不做 ADSR、不接键盘。**波形是固定的正弦**——它的作用是把整条输出链路先立起来，将来换成 A 的音频核心。

## 3. 时钟方案（关键决策）

### 3.1 两个时钟域

```
板载晶振 / 内部 OSC
        │
        ▼
   [ Gowin_PLL ]
        ├──> clk_fsys  100 MHz    系统域：UART、LED、键盘扫描（阶段2才有）
        └──> clk_fs   12.288 MHz  音频域：采样节拍、I2S 位时钟
                        │
                        ├── /256 ──> sample_tick  48 kHz（音频唯一节拍）
                        └── /4   ──> HP_BCK       3.072 MHz
```

### 3.2 为什么音频域必须是 12.288 MHz

12,288,000 ÷ 256 = **48,000 整除**。

如果直接用 100 MHz 分频：100,000,000 ÷ 48,000 = **2083.33**，除不尽 → 需要小数累加 → **产生抖动**。而赛题拓展要求里明确写着"**确定性无抖动延迟**"，所以这一步不能将就。

### 3.3 PLL 参数（供 `.ipc` 配置用）

假设参考时钟 `f_ref = 50 MHz`（内部 OSC 或板载晶振）：

```
VCO = f_ref × (M / N)
clkout = VCO / D

取 M = 64,  N = 25  →  VCO = 50 × 2.56 = 128 MHz
  D = 1.00 → 128.00 MHz    ← 接近 100 MHz，但不够准
```

**更优的一组**（同时精确产出两个频率）：

```
VCO = 1228.8 MHz（PLL 输出频率上限内，需在 IP 配置器里确认）
  D = 100 → 12.288 MHz   ✅ 精确
  D = 12.288 → 无法用整数分频得到 100 MHz ❌
```

**结论：100 MHz 和 12.288 MHz 无法用同一个 PLL 的整数分频同时精确得到。**

因此采用**两个 PLL**（板载有 12 个 PLL，够用）：

| PLL | 输入 | 输出 | 用途 |
|---|---|---|---|
| `PLL_A` | 50 MHz | **12.288 MHz** | 音频域，必须精确 |
| `PLL_B` | 50 MHz | **100 MHz**（50 × 2） | 系统域，整数倍，精确 |

**C1 阶段其实只需要 `PLL_A`** —— 因为这一步还没有键盘和 UART。`PLL_B` 到阶段 2 再接。

### 3.4 降级方案（重要）

板载晶振的频率目前**还没确认**（官方例程用的是内部 `Gowin_OSC`，没接外部晶振）。

所以 `clock_gen.v` 设计成**参数化**：

```verilog
parameter CLK_SRC = "OSC";   // "OSC" = 用内部振荡器；"EXT" = 用外部晶振
```

- 第一版直接用 `Gowin_OSC`（内部振荡器，省掉查晶振的事），先把声音弄响
- 等确认了晶振频率，改一个参数就切到外部

> 这符合"先让声音响起来比一步到位更重要"的原则。

## 4. 采样节拍（sample_scheduler）

三个输出：

| 信号 | 频率 | 波形 | 用途 |
|---|---|---|---|
| `sample_tick` | 48 kHz | **单拍脉冲**（1 个 clk_fs 周期宽） | 音频核心的唯一样本节拍 |
| `bck_en` | 3.072 MHz | 时钟使能（不是门控时钟！） | I2S 位时钟的节拍 |
| `bck` | 3.072 MHz | 方波输出 | 送给 `HP_BCK` |

**实现要点**

- 12.288 MHz ÷ 4 = 3.072 MHz → 2 位计数器
- 12.288 MHz ÷ 256 = 48 kHz → 8 位计数器，计到 0 时拉高一个 `clk_fs` 周期
- **计数器和脉冲与 I2S 帧天然对齐**：256 / 4 = 64，正好一帧 64 个 BCK

> **绝不要用门控时钟**（`assign gated_clk = clk & en`）。FPGA 里要用**时钟使能**（`if (en) ...`），门控时钟会产生毛刺和时序问题。

## 5. I2S 发送器（i2s_tx）

### 5.1 协议参数（已从官方例程核实）

| 参数 | 值 |
|---|---|
| BCK | 3.072 MHz = 64 × LRCK |
| LRCK（HP_WS） | 48 kHz，**低电平 = 左声道** |
| 每声道槽位 | 32 bit |
| 有效数据 | 24 bit，**左对齐放在 32 bit 槽的高 24 位**，低 8 位补 0 |
| 位序 | **MSB 先出** |
| 发送边沿 | 在 BCK 下降沿更新数据 |

### 5.2 ⚠️ 一个必须注意的细节：WS 相位

官方例程里 `HP_WS` 的翻转位置**不是标准 I2S 的 1 个 BCK 延迟**：

```verilog
HP_WS_r <= (b_cnt == 5'd3) ? 1'b0 : ((b_cnt == 5'd19) ? 1'b1 : HP_WS_r);
//                         ↑ 第 3 个 BCK 拉低（左）      ↑ 第 19 个 BCK 拉高（右）
```

**我的做法**：把这个相位做成参数

```verilog
parameter WS_LEFT_PHASE  = 6'd3;    // 左声道起点
parameter WS_RIGHT_PHASE = 6'd19;   // 右声道起点
```

**第一版先照抄官方的 3 / 19**，实测确认能出声之后，再试着改成标准 I2S 相位。**不要凭理论推断**——官方参数是实机验证过的。

### 5.3 实现结构

```
        24 位左采样 ─┐
        24 位右采样 ─┴─> [ 32 位槽移位寄存器 ] ─> HP_DIN
                                ▲
        bck (下降沿) ───────────┘
                                │
        [ 帧计数器 0..63 ] ──> [ WS 相位比较器 ] ──> HP_WS
```

- 帧计数器 `b_cnt` 范围 0~63，一个 BCK 加一
- `b_cnt == WS_LEFT_PHASE` → WS 拉低（左声道），加载左采样
- `b_cnt == WS_RIGHT_PHASE` → WS 拉高（右声道），加载右采样
- 每位在 BCK 下降沿移出

## 6. 音源（tone_src）：**临时的，将来会删**

### 6.1 它是什么

一个**固定频率正弦波**发生器：相位累加器 + 正弦波表 ROM。

| 参数 | 值 | 说明 |
|---|---|---|
| 频率 | 1000 Hz（1 kHz） | 便于用示波器/频谱确认 |
| 波表深度 | 256 点 | 小，够用 |
| 波表位宽 | 16 bit 有符号 | 换算成 24 bit 输出 |
| 相位累加器 | 32 bit | 频率分辨率足够 |

相位增量计算：

```
fout = SAMPLE_RATE × (phase_inc / 2^32)
1000 = 48000 × (phase_inc / 4294967296)
phase_inc = 4294967296 × 1000 / 48000 ≈ 89,478,485
```

### 6.2 为什么它必须存在，又必须消失

- **必须存在**：C1 阶段 A 的音频核心还没做好，需要有个音源把链路点亮
- **必须消失**：赛题**严禁**"预录 PCM 播放"。所以：
  - 它只做**单音正弦**，不播放任何音频片段
  - 它放在 `rtl/system/`，接口和 A 的 `audio_core` **完全一致**（24 位采样 + valid）
  - 阶段 2 集成时，把 `tone_src` 换成 `audio_core` 即可，顶层其他部分不动

> **合规说明要写进报告**：C1 阶段的固定正弦是**链路调试信号**，不是音频内容；最终作品的全部音频由播放动作实时合成。

## 7. 顶层（synth_top）

```
        ┌────────────────────────────────────────────┐
  OSC ──┤ clock_gen → clk_fs (12.288M) / clk_fsys    │
        │      │                                      │
  rst ──┤ reset_sync → rst_n                         │
        │      │                                      │
        │ sample_scheduler                            │
        │   ├─ sample_tick (48k) ──> tone_src         │
        │   └─ bck / bck_en ──────> i2s_tx            │
        │                              ▲              │
        │        tone_src ── 24bit L/R─┘              │
        │                              │              │
        │                         i2s_tx              │
        └──────────────┬───────────────┬──────────────┘
                 HP_BCK│        HP_WS│        HP_DIN│        PA_EN
                       ▼              ▼              ▼          ▼
                       板载 DAC → 板载功放 → 耳机口 / 扬声器
```

**输出端口（管脚已核实，直接接约束）**

| 端口 | 管脚 | 说明 |
|---|---|---|
| `HP_BCK` | Y17 | 位时钟 |
| `HP_WS` | AB17 | 声道，低=左 |
| `HP_DIN` | AA16 | 数据 |
| `PA_EN` | AB16 | 功放使能，**高有效** |
| `rst_ext` | F4 | S2 按键，1.5V 电平域 |
| `led` | W21 | 心跳指示（证明系统在跑） |

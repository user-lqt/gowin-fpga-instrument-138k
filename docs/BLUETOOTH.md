## 连接与网页

ESP GPIO21 TX接FPGA C18，ESP GPIO20 RX接FPGA C19，共地，UART115200/8N1、3.3V逻辑。ESP监视日志使用USB Serial/JTAG，不与这两根线混用。

将 `companion/phone/` 整个目录部署到HTTPS静态站点，保留index.html、app.js、protocol.js的相对位置。Android Chrome开启蓝牙后打开该页，点连接并选择设备。电脑本机开发可用localhost；手机访问局域网普通HTTP一般不满足Web Bluetooth安全上下文。iPhone Safari不提供该网页所需的Web Bluetooth。

本次提供源文件，不假称已经发布新网页地址。旧页面中的帮助文案和版号保留原样；最终硬件引脚按本仓库[当前接线](HARDWARE.md)，不按旧网页年代推断。

## BLE服务

| 项目 | UUID |
| --- | --- |
| 服务 | `6e400001-b5a3-f393-e0a9-e50e24dcca9e` |
| RX写入特征 | `6e400002-b5a3-f393-e0a9-e50e24dcca9e` |
| TX通知特征 | `6e400003-b5a3-f393-e0a9-e50e24dcca9e` |

调试器连接服务后，订阅TX通知，往RX写入十六进制字节。ESP源码也支持HEX文本输入，但二进制原始帧最直接。FPGA命令为5字节：`A5 CMD A B CHECK`，CHECK为前四字节异或。

| 用途 | 完整帧 |
| --- | --- |
| MIDI60发声，力度100 | `A5 90 3C 64 6D` |
| MIDI60松键 | `A5 80 3C 00 19` |
| SONG启动内置曲1 | `A5 B0 01 00 14` |
| SONG启动内置曲2 | `A5 B0 02 00 17` |
| SONG启动上传曲3 | `A5 B0 03 00 16` |
| 自由练习 | `A5 B1 00 00 14` |
| 节奏练习 | `A5 B1 01 00 15` |
| 80 BPM | `A5 B2 50 00 47` |
| 停止指引 | `A5 B3 00 00 16` |
| 恢复默认键位 | `A5 D1 00 00 74` |
| 开始记录 | `A5 E0 00 00 45` |
| 停止记录 | `A5 E1 00 00 44` |
| 取回记录 | `A5 E2 00 00 47` |
| 状态查询 | `A5 F0 00 00 55` |

选曲需要先进入SONG，第三槽需要有效曲谱。ESP的UART OK只表示向串口发送完成；FPGA的A6回包才是指令处理回执。每条控制命令等待回执后再发送下一条。

## 曲谱下载

txt/csv每行两列：物理键号与时值。0为休止，1至24为物理键；当前原样保留版本不接受下载键号6。时值1至32，以八分音符为单位，最多128项。

```text
5 2
5 2
8 2
10 4
0 2
```

协议依次C0（A=项数，B=0）开始、C1（A=键号，B=时值）逐项追加、C2（0,0）提交，C3（0,0）中止。上传前停止现有指引；完成后在SONG启动第三槽。只有点击读取文件并不表示已经下载到FPGA。

## 自定义键位

D0：A=键号1至24，B=MIDI0至127。默认K1=60，K24=83；目标音符不可与其他键重复，操作前松开所有键。D1恢复默认。LED仍跟随物理键，正式曲目演奏前宜恢复映射。临时映射存于RAM，断电清除。

## 记录 回传与回放

记录的是NOTE_ON/NOTE_OFF、力度与时间，**不是PCM、麦克风或实际音色波形录音**。最多512事件，一次按下与松开占两项；固定48采样计数的时间基准约为1ms，实际换算随真实Fs。

操作为开始记录 → 演奏 → 停止 → 取回 → 等事件数量完整 → 保存JSON/MIDI或回放。取回按约30ms间隔发送记录，满容量需约16秒。断线后重新连接、订阅并取回，不把不完整数据导出为成功。

回包12字节，以A6开头，整包异或为0；多字节整数低位在前：F0为命令回执，E0为事件，E1为取回结束与总数。BLE通知边界不是协议包边界，网页解析器处理分片及混合ASCII提示。手机按事件时间回放会受BLE调度影响，不将其作为整机硬实时延迟的测量方式。

## ESP工程使用边界

ESP工程使用ESP-IDF与NimBLE，GPIO/服务配置见main.c及sdkconfig。这里只归档现有源文件，未携带本机build缓存、密钥或依赖下载目录。首次重新构建应在匹配的ESP-IDF环境中核对target为esp32c3、NimBLE启用、控制台为USB Serial/JTAG；已烧录可用的ESP无需因本次仓库整理重刷。

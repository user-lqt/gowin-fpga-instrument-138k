## 信号与控制分配

`MCP3008 CH0 → fsr_expression_control → expression_mapper → 参数队列 D → PARAM_MODULATION → pitch_expression_bank → 振荡器/弦周期 → 混音 → PCM 帧缓存 → DAC`。

- CH0：FSR 控制全局颤音深度，影响全部声部。
- CH1：已确认接好摇杆 X，控制连续弯音，保留与颤音同时使用。
- CH2：仍参与 ADC 轮询，Y 轴的颤音参数不进入整机音频队列。
- 编码器 A/B、摇杆 X、FSR 分别进入四路参数队列，同周期更新按 A/B/C/D 排序。

共享采样器每 4096 个 12.288 MHz 时钟启动一次转换，三通道轮询后每通道
约 1 kS/s。FSR 首次有效样本直接初始化，随后用带 8 位小数的 EMA 滤波，
系数为 1/8；只发布变化后的深度，避免重复填满参数队列。

## 参数与接线

FSR 分压方向为 `3.3 V → FSR → ADC 节点 → 5.1 kΩ → GND`，ADC 节点接
MCP3008 CH0。3.3 V 同时作为 MCP3008 的 VDD 与 VREF，所有设备共地。
反向分压需要重新设置映射，不能直接使用以下估计值。

| 参数 | 当前估计与含义 |
| --- | --- |
| 无压力阻值 | 约 4.2 kΩ，理想 ADC 约 561 |
| 重压阻值 | 约 420 Ω，理想 ADC 约 945 |
| `FSR_ZERO_LEVEL` | 570 |
| `FSR_DEADBAND` | 8；滤波 ADC ≤578 时深度为 0 |
| `FSR_FULL_SCALE` | 945；达到或超过此值时深度饱和到 65535 |
| 中间映射 | `(ADC−570)×65535/375`，沿用已交付的压力映射规则 |
| 颤音速度 | 24 位 LFO 每采样加 1748，48 kHz 下约 5.001 Hz |
| 最大深度 | ±0.5 半音，即约 ±50 音分 |
| 深度平滑 | 每采样最多改变 256，满量程变化约 5.33 ms |

这些是根据用户实测阻值设置的估计值，不是整机 ADC 实测标定结果。
深度为 32768 时约为 ±25 音分，深度为 0 时恢复基准音高；LFO 相位持续运行。

## 音频与工程变化

接入 A 的 32 声部 RTL，开启 `ENABLE_EXPRESSION=1`，当前顶层配置
`ENABLE_GUITAR=0`。用户可选音色只有钢琴与编钟，保留原音频ID 0/2；
原来的键盘、双 EC11、RGB、ADC 管脚约束继续作为整机入口。

32 声部的 PCM 有效点为 sample_tick 后 109 个音频时钟。新增
`audio_frame_buffer` 在 DAC 帧边界同时提交左右样本，避免核心在两次声道装载
之间更新而导致左右读到不同帧。该缓存增加一个帧缓冲阶段，属于音频后端延迟，
不据此宣称输入到输出的总延迟已实测通过。

顶层 `MASTER_GAIN_SHIFT=5` 将 UI 音量映射到 1/32 的混音增益范围，为
32 声部求和预留余量；UI 的 0～127 音量显示保持对应旋钮的位置。
单键最大音量可能较原 4 声部固件降低，需在真实 DAC 和音箱上确认听感。


覆盖压力滤波/死区/饱和、LFO 频率与深度、四源参数冲突、左右帧一致性、
32 声部和弯音/滑音/颤音的采样预算，以及实际 SPI 模型到键盘持续音和 DAC
装载的整链路。键盘及 RGB 回归使用独立测试，不将模拟 ADC 当成硬件验收。

上板时先把摇杆回中，按住一个琴键持续发声：

1. 不压 FSR，音高应稳定。
2. 轻压、重压，音高应以约每秒 5 次的速度上下摆动，压力越大幅度越深。
3. 松开 FSR，琴键仍保持声音，音高回稳。
4. 在按住琴键和压住 FSR 时拨动摇杆 X，应同时出现弯音和颤音。
5. 松开琴键，进入尾音后停止发声；不应新增音符或出现持续卡音。

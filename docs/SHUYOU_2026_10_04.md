## Build and simulation

Run from the repository root:

```powershell
& 'E:\Gowin\Gowin_V1.9.12_x64\IDE\bin\gw_sh.exe' tools/build_ec11_j13.tcl
powershell -ExecutionPolicy Bypass -File tools/verify_strike_expression.ps1
```

Adjust the executable paths to local installations. The build script resolves
source paths from its own location; it does not require this checkout path.
The verification script uses Vivado 2022.2 XSim, not Gowin synthesis, and needs
its simulator path adjusted if Vivado is installed elsewhere.

## Wiring and behavior

| EC11 signal | J13 position | Board silk/FPGA ball |
| --- | --- | --- |
| A | 17 | A21 |
| B | 18 | B21 |
| D (push switch) | 19 | B18 |
| C and E | 12 or another common GND | GND |

A/B/D each use a separate 4.7k pull-up to 3.3 V. J13-11 is 5 V and must not
be used for GPIO or pull-ups. Keyboard, LCD and audio assignments are unchanged.
See `KEYBOARD_24_PINOUT.md` and `EC11_DIAGNOSTIC.md` for details.

After reset rotation controls volume (0..127, default 64, step 1).
Pressing the encoder toggles volume/instrument pages; rotation on the instrument
page selects the three timbres. This snapshot does NOT implement press-to-cycle
timbre while always rotating volume. Diagnostic boxes and counters are retained.

Dual-contact keyboard strike timing retains the latest requested behavior:
approximately under 1 second gives normal pitch/gain; slow travel gives one
octave lower and approximately 40% gain. This is contact-to-contact travel,
not total key hold time. The current audio core has four voices, not 32.

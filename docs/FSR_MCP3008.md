# FSR / MCP3008 压力表情输入

## 目的

这部分实现阶段四计划中的全局连续压力表情：FSR 的模拟电压接 MCP3008
`CH0`，FPGA 通过 SPI 读取 10 位采样值，并输出冻结接口中的
`PARAM_MODULATION`（16 位颤音深度）。代码目前作为可复用输入模块交付，
没有改动已经可演奏的整机顶层。

## 文件

- `rtl/input/mcp3008_spi.v`：MCP3008 单端 SPI Mode 0 主机，读取一帧 10 位数据。
- `rtl/input/pressure_adc.v`：定时采样、EMA 一阶滤波、校准映射和状态输出。
- `rtl/input/expression_mapper.v`：ADC 值限幅、死区、16 位表情参数映射和可选故障窗口。
- `sim/input_tb/tb_pressure_adc.v`：MCP3008 行为模型和 SPI/滤波/映射检查。

## 默认参数

`pressure_adc` 默认按 12.288 MHz 系统时钟工作，SPI 分频为 12（约 512 kHz），
采样启动间隔为 12288 个系统时钟（约 1 kS/s），滤波系数为 `1/8`。默认
按实测 FSR 阻值约 4.2 kΩ（0 压）到 420 Ω（重压），并假定 FSR 接 3.3 V、
5.1 kΩ 接地、分压点接 CH0，估计 ADC 约为 561 到 946。当前默认起始值为
`ZERO_LEVEL=570`、`FULL_SCALE=945`、`DEADBAND=8`，将压力范围映射到
`0..65535`。上板后应以实际 ADC 读数微调；若 FSR 与电阻位置对调，压力变化
方向会相反。

输出 `sensor_fault` 只有在启用 `ENABLE_FAULT_CHECK` 并超出配置的
`FAULT_LOW_LEVEL..FAULT_HIGH_LEVEL` 时置位；不同分压接法的断线表现不同，
所以故障窗口必须根据实测值配置，不能假定所有模块的断线方向相同。

## 接线

FSR 使用分压电路产生 0..3.3 V 模拟电压，分压节点接 MCP3008 `CH0`；MCP3008
与 FPGA 共地并使用 3.3 V 逻辑。当前已确认的 J13 规划为：

| MCP3008 | FPGA 板端 |
|---|---|
| `CS` | J13-24 / A18 |
| `CLK` | J13-25 / D15 |
| `DIN` | J13-26 / D14 |
| `DOUT` | J13-27 / D16 |

FSR 的电阻值和分压电阻决定 ADC 的方向与量程。上板前应先只接 ADC，记录松压、
轻压、重压三组 `raw_value`，再调整 `ZERO_LEVEL`、`FULL_SCALE` 和可选死区。

## 验证状态

- **仿真已证明**：SPI 命令为单端 `CH0`，16 个时钟内正确接收 10 位数据；
  EMA 首样本初始化和 16 位映射通过。
- **综合待确认**：需要在目标 Gowin 工程中加入三个 RTL 文件并检查资源、时序。
- **上板必须测量**：MCP3008 供电、SPI 波形、松压/满压 ADC 数值、断线行为和
  实际颤音响应。当前没有把模块接入整机 `input_top`，因此不会宣称整机颤音已经完成。

### 三、⚠️ 已知偏差：音频时钟不是精确的 12.288 MHz

**这是本批最重要的发现，必须记录。**

已核实 GW5AST 的 `PLL` 原语只有整数分频：

```
f_VCO     = FCLKIN / IDIV_SEL * FBDIV_SEL * MDIV_SEL
f_CLKOUTn = f_VCO / ODIVn_SEL          (ODIVn_SEL 取值 1..128)
```

对参考频率穷举后的结论：

| 参考频率 | 最优结果 | 偏差 |
|---|---|---|
| **50 MHz**（外部晶振） | **12.29167 MHz** | **+298 ppm** |
| 49.152 MHz | 精确 12.288 MHz | 0（但 49.152 MHz 不可得） |
| 内部 OSC | 基频未知 | 不可用 |

**当前配置**：`IDIV=1, FBDIV=1, MDIV=59, ODIV0=80`

```
VCO = 50 MHz × 59 = 2950 MHz  ← 超出常见 VCO 上限，实际由工具重算
CLKOUT0 = 12.29167 MHz
LRCK    = 12,291,667 ÷ 256 = 48,014.9 Hz   （偏离 +0.031%，约 +0.5 音分）
```

**影响评估**：+0.5 音分远小于人耳可辨阈值（5~10 音分），**音乐上完全可接受**。
且 LRCK 仍在"约 48 kHz"，满足赛题基础要求的验收口径。

**修正路径（阶段 2 处理，三选一）**

| 方案 | 做法 | 优点 |
|---|---|---|
| A. 焊 12.288 MHz 有源晶振 | 接 `i_clk_in`，`MDIV=1, ODIV0=2` | 最简单直接 |
| **B. 用板载 MS5351** | FPGA 通过 UART 配置 MS5351 输出 12.288 MHz | **最优雅**，板载已有该芯片 |
| C. 换 24.576 MHz 晶振 | `MDIV=1, ODIV0=2` | 常见频点，易采购 |

### 四、另外两个"踩坑记录"（避免重复）

**1. GW5AST 没有 `rPLL` 原语。**
实例化 `rPLL` 会报 `Instantiating unknown module 'rPLL'`。
GW5AST 用 **`PLL`** 原语（7 路输出，含 `MDIV_SEL`/`ODIV0..6_SEL`）。
（`rPLL` 是 GW1N/GW2A 系列的原语。）

**2. 位选比较会让综合器折叠成 1 位比较。**
`sample_scheduler` 最初写成：

```verilog
localparam BCK_TOGGLE_AT = CLK_DIV_BCK - 1;
if (cnt[CLK_DIV_BCK-1:0] == BCK_TOGGLE_AT[CLK_DIV_BCK-1:0]) bck <= ~bck;
```

实测结果：**bck 每 16 拍才翻转一次**（应为每 4 拍），
原因是局部常量的位选在综合时被折叠成 1 位，比较退化成了按位与。

**修正**：改用独立的 `bck_cnt` 计数器 + 完整表达式比较：

```verilog
wire bck_last = (bck_cnt == CLK_DIV_BCK[BCK_W-1:0] - 1'b1);
```

修正后仿真实测 `n_ben = 150`（期望 150），完全正确。

> **教训**：不要对 localparam 做部分位选后参与比较，直接用完整位宽比较。
